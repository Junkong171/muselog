# F-024: 아이디어 음성 메모

- 상태: 구현됨
- 작성일: 2026-11-06
- 관련 파일: `src/Inspiration.jsx`, `src/Notebook.jsx`, `src/lib/inspiration.js`, `src/lib/inspiration.test.js`, 새 파일 `src/voiceMemo.js`(녹음·기기 저장), `src/App.css`, `public/privacy.html`, `CLAUDE.md`

## 목적

멜로디가 떠올랐을 때 글로 적기 어렵다. 영감 탭에서 바로 흥얼거림을 녹음해 아이디어와 함께 저장하고, 수첩 탭에서 다시 들을 수 있게 한다.

## 사용자 시나리오

1. 영감 탭 "아이디어 메모" 카드에서 **녹음** 버튼을 누른다. 처음이면 브라우저가 마이크 허용을 묻는다.
2. 녹음 중에는 흐른 시간(예: `0:07`)과 **녹음 끝** 버튼이 보인다. 최대 2분이 되면 저절로 끝난다.
3. 녹음이 끝나면 **들어보기** / **지우기** 버튼과 녹음 길이가 보인다. 마음에 안 들면 지우고 다시 녹음한다.
4. 메모 글(없어도 됨)과 함께 **아이디어 저장**을 누른다.
5. 수첩 탭에서 그 아이디어에 `🎤 0:07` 표시와 **녹음 듣기** 버튼이 보이고, 눌러서 다시 듣는다.
6. 아이디어를 삭제하면 녹음도 함께 지워진다.

## 수용 기준

- [ ] AC-1: 영감 탭 "아이디어 메모" 카드에 **녹음** 버튼이 있다. 누르면 마이크를 켜고, 녹음 중에는 흐른 시간(`분:초`)과 **녹음 끝** 버튼이 보인다.
- [ ] AC-2: **녹음 끝**을 누르거나 2분이 되면 녹음이 멈추고 마이크가 꺼진다. 녹음 길이와 **들어보기**, **지우기** 버튼이 보인다.
- [ ] AC-3: 녹음이 있으면 메모 글이 비어 있어도 **아이디어 저장**이 된다. 녹음도 글도 없으면 지금처럼 "메모를 적어 주세요."가 보인다.
- [ ] AC-4: 저장하면 녹음 미리듣기가 사라지고, 수첩 탭의 그 아이디어에 녹음 길이와 **녹음 듣기** 버튼이 보인다. 글 없는 아이디어는 글 자리에 "음성 메모"가 보인다.
- [ ] AC-5: 수첩에서 **녹음 듣기**를 누르면 녹음이 재생되고 버튼이 **정지**로 바뀐다. 다 들으면 다시 **녹음 듣기**가 된다.
- [ ] AC-6: 녹음은 새로고침하거나 앱을 닫았다 열어도 남아 있다 (브라우저의 IndexedDB에 저장).
- [ ] AC-7: 수첩에서 아이디어를 삭제하면 그 녹음도 IndexedDB에서 지워진다.
- [ ] AC-8: 녹음 파일이 이 기기에 없으면(다른 기기에서 동기화로 받은 아이디어 등) **녹음 듣기** 대신 "녹음은 녹음한 기기에서만 들을 수 있어요."가 보인다.
- [ ] AC-9: 마이크를 허락하지 않았거나, 마이크·녹음 기능이 없는 브라우저면 녹음 버튼 아래에 이유를 한국어로 안내하고, 다른 기능은 그대로 쓸 수 있다.
- [ ] AC-10: 녹음 중에 다른 탭으로 옮기면 녹음이 멈추고 마이크가 꺼진다 (녹음은 버린다).
- [ ] AC-11: 예전 아이디어(`audioSeconds` 없음)는 녹음 없음으로 읽히고 지금처럼 보인다. `normalizeIdeas` 테스트로 확인한다.
- [ ] AC-12: 개인정보처리방침에 "아이디어 음성 메모는 이 기기 브라우저에만 저장하고, 계정·서버로 보내지 않는다"가 적혀 있다.
- [ ] AC-13: `npm test`, `npm run build`, `npm run lint`가 오류 없이 끝난다.

## 비범위

- 녹음 파일을 계정(Supabase)에 올리거나 다른 기기와 동기화하기, 백업 파일에 넣기 (기기에만 둔다)
- 수첩에서 이미 저장한 아이디어에 녹음을 새로 넣거나 바꾸기
- 녹음 자르기, 음 높이 분석, 악보로 바꾸기
- 코드 진행을 틀어 놓고 그 위에 녹음하기
- 쓰지 않는 녹음 파일을 따로 찾아 정리하기 (백업 불러오기로 아이디어가 바뀌어 남은 녹음 등)

## 데이터 영향

| 항목 | 내용 |
|---|---|
| 사용하는 localStorage 키 | `muselog-ideas` (읽기 / 쓰기) |
| 데이터 구조 변경 | 있음: 아이디어에 `audioSeconds`(녹음 길이, 초, 0 = 녹음 없음) 추가. 녹음이 있으면 `text`가 `""`일 수 있음 (0~500자) |
| 새 저장소 | 브라우저 IndexedDB `muselog-audio`, 저장소 `memos`, 열쇠 = 아이디어 `id`, 값 = 녹음 파일(Blob). localStorage는 용량이 작아(약 5MB) 소리를 넣지 않는다 |
| 백업·동기화 | `audioSeconds`는 아이디어와 함께 백업·동기화된다. 녹음 파일 자체는 넣지 않는다 (`BACKUP_KEYS` 변경 없음) |
| 마이그레이션 | 필요: `normalizeIdeas`가 `audioSeconds`가 없거나 깨진 값이면 0으로 읽는다. 글 없는 아이디어는 `audioSeconds > 0`일 때만 남긴다. 예전 데이터는 그대로 보인다 |

## 확인 방법

- 자동: `npm test`, `npm run build`, `npm run lint`
- 수동 (브라우저):
  1. `npm run dev` 실행 후 http://localhost:5173/ 열기
  2. 영감 탭에서 **녹음** → 몇 초 말하기 → **녹음 끝** → **들어보기**로 들리는지 확인
  3. 글 없이 **아이디어 저장** → 수첩 탭에 "음성 메모"와 녹음 길이, **녹음 듣기**가 보이는지 확인
  4. 새로고침 후 **녹음 듣기**가 되는지 확인
  5. 아이디어 삭제 후 개발자 도구 Application → IndexedDB → `muselog-audio`에서 사라졌는지 확인
  6. 마이크 허용을 막고 **녹음** → 안내 문구 확인
  7. 휴대폰(설치한 앱)에서 녹음과 듣기가 되는지 확인
