# F-005: 작업실 탭과 메트로놈

- 상태: 구현됨 (수정 1차: ♩ = BPM 표시, 리듬(박 나누기) 추가 / 수정 2차: 박마다 강조 고르기, 셋잇단 음표 기호, 박자 수를 줄일 때 1번 박부터 / 수정 3차: BPM 직접 입력, BPM 범위 10~300)
- 작성일: 2026-10-26
- 관련 파일: `src/App.jsx` (탭 목록 `TABS`/`TAB_ICONS`, 탭별 화면 분기, 연습 기록 저장 `recordPractice`/`addPracticeLog`), 새 파일 `src/Metronome.jsx`, `src/lib/metronome.js`, `src/lib/metronome.test.js`, `src/App.css`, `CLAUDE.md` (폴더 구조, localStorage 키 표)

## 목적

연습할 때 다른 앱을 따로 켜지 않고 MUSELOG 안에서 메트로놈을 쓰게 한다. "작업실" 탭을 새로 만들어 음악 도구를 모아 두고, 첫 도구로 메트로놈을 넣는다. 메트로놈으로 연습한 시간은 바로 연습 기록에 남길 수 있다. 튜너 같은 도구는 나중에 이 탭에 추가한다.

## 사용자 시나리오

1. 사용자가 사이드바에서 "작업실" 탭을 누른다.
2. 메트로놈 카드가 보인다. BPM을 90으로 맞추고, 박자를 "3박"으로 고른 뒤 "시작"을 누른다.
3. 첫 박은 높은 소리, 나머지 박은 낮은 소리로 "딱-틱-틱"이 반복되고, 박 버튼이 박자에 맞춰 차례로 켜진다.
3a. 4박으로 바꾸고 박 버튼 "1"과 "3"만 강조로 고르면 "딱-틱-딱-틱"이 된다. "2"와 "3"만 고르면 "틱-딱-딱-틱"이 된다.
4. 곡의 빠르기를 모를 때는 "탭" 버튼을 박자에 맞춰 여러 번 눌러 BPM을 맞춘다.
5. 10분 연습한 뒤 "정지"를 누르고, 곡을 골라 "연습 기록에 저장"을 누른다.
6. "연습 기록" 탭에 10분짜리 기록이 생기고, 다음에 "작업실"을 열면 BPM 90, 3박 설정이 그대로 있다.

## 수용 기준

### 작업실 탭

- [ ] AC-1: 사이드바 탭 목록 맨 아래(캘린더 다음)에 "작업실" 탭이 아이콘과 함께 보인다. 누르면 상단 경로가 "Workspace / 작업실"로 바뀐다.
- [ ] AC-2: "작업실" 화면에는 제목 영역(영문 작은 제목, "작업실" 제목, 설명 한 줄)과 메트로놈 카드가 보인다. 카드 아래에 "튜너 등 다른 도구는 곧 추가될 예정이에요." 같은 안내 문구가 보인다.

### 메트로놈 기본

- [ ] AC-3: 메트로놈 카드에 현재 빠르기가 악보 표기처럼 "♩ = 120" 형식으로 크게 보이고, BPM을 바꾸는 슬라이더와 "−", "+" 버튼(1씩)이 있다. BPM은 10~300 안에서만 바뀐다. (10에서 "−", 300에서 "+"를 눌러도 범위를 벗어나지 않는다)
- [ ] AC-3a: "♩ = 120"의 숫자 부분은 입력 칸이라 눌러서 BPM을 직접 입력할 수 있다. (숫자만 입력되고, 최대 3자리) 입력하는 동안에는 메트로놈 빠르기가 바뀌지 않고, Enter를 누르거나 칸 밖을 누르면 적용된다. 입력값이 10보다 작으면 10, 300보다 크면 300으로 맞춰 적용된다. 칸을 비우고 나오거나 Esc를 누르면 입력 전 BPM으로 돌아간다. 슬라이더·"−"/"+"·탭으로 BPM이 바뀌면 입력 칸 숫자도 바로 따라 바뀐다.
- [ ] AC-4: 마디당 박자 수를 "2박", "3박", "4박", "6박" 중에서 고를 수 있다. 처음 쓰는 경우 기본값은 BPM 120, 4박, 1번 박만 강조다.
- [ ] AC-5: "시작" 버튼을 누르면 클릭 소리가 BPM 빠르기로 반복되고 버튼 글자가 "정지"로 바뀐다. "정지"를 누르면 소리가 멈추고 "시작"으로 돌아온다.
- [ ] AC-6: 소리는 Web Audio API(브라우저에서 소리를 직접 만드는 기능)로 만들고, 음원 파일이나 새 라이브러리를 추가하지 않는다. 소리는 미리 예약하는 방식으로 재생해, 박 간격이 `setInterval` 시간 오차에 따라 흔들리지 않게 한다.
- [ ] AC-7: 재생 중에 BPM, 박자 수, 강조할 박을 바꾸면 멈추지 않고 다음 박부터 바뀐 값이 적용된다. 박자 수를 줄여서 다음 박 번호가 새 박자 수를 넘으면(예: 6박의 5번째 박에서 3박으로 바꿈) 다음 박은 1번 박부터 시작한다.
- [ ] AC-8: 박자 수만큼 번호가 붙은 박 버튼("1", "2", …)이 한 줄로 보이고, 재생 중에는 지금 소리 나는 박의 버튼이 켜져서 1번부터 차례로 옮겨 간다. 정지하면 모든 버튼의 켜짐 표시가 꺼진다.

### 박마다 강조 고르기

- [ ] AC-9: 박 버튼을 누를 때마다 그 박의 강조가 켜지고 꺼진다. 강조가 켜진 박 버튼은 색과 테두리가 달라 한눈에 구분된다. 여러 박을 함께 강조할 수 있고(예: 4박에서 1·3번, 또는 2·3번), 하나도 강조하지 않을 수도 있다. 버튼 근처에 "숫자를 눌러 강조할 박을 고르세요." 같은 안내가 보인다. ("첫 박 강조" 체크박스는 없어진다)
- [ ] AC-9-1: 강조된 박은 높은 소리, 강조되지 않은 박은 보통 소리로 난다. 강조된 박이 하나도 없으면 모든 박이 같은 소리로 난다. 강조는 그 박의 첫 번째 소리에만 붙고, 리듬의 박 사이 소리(AC-9b)는 강조와 상관없이 늘 낮고 작은 소리다.
- [ ] AC-9-2: 박자 수를 바꿔도 강조 고른 내용은 번호대로 유지된다. (예: 4박에서 1·3번 강조 → 3박으로 바꾸면 1·3번 강조 → 다시 4박으로 바꾸면 1·3번 강조) 박자 수보다 큰 번호의 강조는 그 박자에서는 소리와 화면에 쓰이지 않는다.

### 리듬 (박 나누기)

- [ ] AC-9a: "리듬"을 음표 버튼 4개로 고를 수 있다: "♩"(4분음표, 한 박에 1번), "♫"(8분음표, 2번), 셋잇단음표(3번), "♬"(16분음표, 4번). 셋잇단음표 버튼은 한글 글자가 아니라 악보 기호(묶인 8분음표 3개 위에 작은 "3")로 보인다. 처음 쓰는 경우 기본값은 "♩"다. 각 버튼에는 음표 이름이 툴팁/화면 읽기용 이름으로 붙는다.
- [ ] AC-9b: "♩"가 아닌 리듬을 고르면, 한 박 간격(60 / BPM 초)을 똑같이 나눈 시각에 박 사이 소리가 더 난다. (예: BPM 120, "♫"이면 0.25초마다 소리) 박 사이 소리는 박 소리보다 낮고 작다.
- [ ] AC-9c: 박 표시 점은 리듬과 상관없이 박 단위로만 움직인다. 재생 중에 리듬을 바꾸면 멈추지 않고 다음 박부터 적용된다.

### 탭 템포

- [ ] AC-10: "탭" 버튼을 박자에 맞춰 두 번 이상 누르면, 최근 누른 간격(최대 4번 간격)의 평균으로 BPM이 바뀐다. (예: 0.5초 간격으로 누르면 120) 결과는 정수로 반올림하고 10~300 범위로 맞춘다. (탭은 2초 넘게 쉬면 새로 세므로 탭으로 맞출 수 있는 가장 느린 빠르기는 30이다)
- [ ] AC-11: 마지막 탭 뒤 2초가 지나서 다시 누르면 새로 세기 시작한다. (그 한 번으로는 BPM이 바뀌지 않는다)

### 설정 저장

- [ ] AC-12: BPM, 박자 수, 강조할 박, 리듬 설정은 새 localStorage 키 `muselog-metronome`에 저장되어, 새로고침하거나 다른 탭에 갔다 와도 그대로 유지된다.
- [ ] AC-13: `muselog-metronome` 값이 없거나 깨져 있으면(숫자가 아님, 범위 밖, 모르는 박자 수 등) 그 항목만 기본값(BPM 120 / 4박 / 1번 박만 강조 / 리듬 ♩)으로 읽고 앱은 멈추지 않는다. 리듬 항목이 없는 예전 저장값도 리듬 ♩로 읽는다. 강조할 박 목록에서 1~6이 아닌 값이나 중복은 버린다.
- [ ] AC-13a (마이그레이션): 예전 형식 저장값(`accent: true/false`, `accents` 없음)은 `accent: true`면 "1번 박만 강조", `false`면 "강조 없음"으로 바꿔 읽고, 다음 저장부터 새 형식(`accents`)으로 저장된다. (`accent` 항목은 더 이상 저장하지 않는다) 범위 밖 BPM은 10~300으로 맞춘다. 이 처리는 `normalizeMetronome` 함수(`src/lib/metronome.js`)로 한다.

### 연습 기록 연결

- [ ] AC-14: 메트로놈 카드에 "이번 연습 시간"이 `분:초`(예: 3:05) 형식으로 보인다. 재생 중에만 늘어나고, 정지하면 멈춘 채 유지되며, 다시 시작하면 이어서 늘어난다.
- [ ] AC-15: 카드에 연습곡 선택("자유 연습" + 내 연습곡 목록)과 "연습 기록에 저장" 버튼이 있다. 이번 연습 시간이 1분 미만이면 버튼이 눌리지 않고 "1분 이상 연습하면 저장할 수 있어요." 안내가 보인다.
- [ ] AC-16: "연습 기록에 저장"을 누르면 메트로놈이 멈추고, 연습 기록이 하나 추가된다. 시간은 이번 연습 시간을 분으로 반올림한 값(1분 이상), 메모는 "메트로놈 연습 · BPM 120 · 4박"처럼 그때 설정이 들어간다. 리듬이 "♩"가 아니면 뒤에 " · 8분음표"처럼 리듬 이름이 붙는다. 저장 후 이번 연습 시간은 0:00으로 돌아간다.
- [ ] AC-17: 이렇게 저장한 기록은 "연습 기록" 탭 목록, 대시보드의 "오늘의 연습"/"이번 주 연습", "연습 통계" 탭에 연습 기록 탭에서 직접 저장한 기록과 똑같이 반영된다. 기록 형식은 기존과 같다(`{ id, date, minutes, songTitle, note }`).
- [ ] AC-18: "작업실"에서 다른 탭으로 옮기면 메트로놈 소리가 멈추고, 저장하지 않은 이번 연습 시간은 사라진다. (다시 오면 정지 상태, 0:00)

## 확인 방법

- 자동: `npm test`, `npm run build`, `npm run lint`
- 수동 (브라우저, 소리가 나므로 스피커/이어폰 켜기):
  1. `npm run dev` 실행 후 http://localhost:5173/ 열기
  2. 사이드바에서 "작업실"을 눌러 메트로놈 카드가 보이는지 본다. (BPM 120, 4박)
  3. "시작"을 눌러 소리와 박 버튼이 박자에 맞는지 본다. 1번 박이 높은 소리인지 듣는다.
  3a. 박 버튼 "1"을 눌러 강조를 끄고 "3"을 눌러 켜서, 3번 박만 높은 소리가 되는지 듣는다. "2"도 켜서 2·3번이 높은 소리인지 듣는다. 모두 끄면 같은 소리가 되는지 듣는다.
  4. 재생 중에 BPM을 60, 200으로 바꾸고 박자를 3박으로 바꿔 멈추지 않고 바로 바뀌는지 본다. 6박의 뒤쪽 박에서 2박으로 바꿔 1번 박부터 이어지는지 듣는다.
  5. "탭"을 일정하게 4~5번 눌러 BPM이 비슷하게 맞춰지는지 본다.
  5b. "♩ = " 옆 숫자를 눌러 95를 입력하고 Enter를 눌러 95가 되는지 본다. 400을 입력하면 300, 5를 입력하면 10이 되는지, 지우고 Esc를 누르면 원래 값으로 돌아가는지 본다.
