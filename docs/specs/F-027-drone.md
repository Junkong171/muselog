# F-027: 작업실 기준음(드론)

- 상태: 구현됨
- 작성일: 2026-11-06
- 관련 파일: 새 파일 `src/Drone.jsx`, `src/lib/drone.js`, `src/lib/drone.test.js`, `src/App.jsx`(작업실에 카드 추가, 설정 저장), `src/lib/backup.js`(`BACKUP_KEYS`), `src/lib/backup.test.js`(키 개수), `src/App.css`, `public/privacy.html`(저장 항목 목록), `CLAUDE.md`(키 표)

## 목적

계속 울리는 기준음(드론)에 맞춰 소리를 내면 음정이 맞는지 귀로 바로 알 수 있다. 음정·화음 연습에 쓰는 도구를 다른 앱 없이 작업실에서 메트로놈·튜너와 함께 쓸 수 있게 한다.

## 사용자 시나리오

1. 작업실 탭에서 메트로놈 아래 **"기준음"** 카드를 본다.
2. 음(도~시 12개)과 높이(낮게 / 보통 / 높게), 울림(근음만 / 근음+5도 / 장화음 / 단화음)을 고르고 **"켜기"**를 누른다.
3. 소리가 부드럽게 커지며 멈추지 않고 계속 울린다. 그 소리에 맞춰 노래하거나 연주한다.
4. 울리는 중에 음을 바꾸면 소리가 끊기지 않고 새 음으로 바뀐다. 음량 막대로 크기를 조절한다.
5. **"끄기"**를 누르면 소리가 부드럽게 작아지며 멈춘다. 다음에 작업실을 열면 마지막으로 고른 설정이 그대로 있다.

## 수용 기준

- [ ] AC-1: 작업실 탭의 메트로놈 카드와 튜너 카드 사이에 제목 "기준음" 카드가 있다.
- [ ] AC-2: 음 선택은 12개(도 C, 도# C#, 레 D, … 시 B)이고, 높이는 낮게 / 보통 / 높게 3가지, 울림은 근음만 / 근음+5도 / 장화음 / 단화음 4가지다. 카드에 지금 고른 음의 이름과 주파수(Hz, 정수)가 보인다. (예: 라 · 보통 → "A3 · 220Hz")
- [ ] AC-3: 주파수 계산은 튜너와 같은 기준(A4 = 440Hz)이다. 높이 낮게 / 보통 / 높게 = 옥타브 2 / 3 / 4. 근음+5도는 근음과 7반음 위, 장화음은 0·4·7반음, 단화음은 0·3·7반음 위 음을 함께 낸다. (`src/lib/drone.js`의 순수 함수와 테스트로 확인)
- [ ] AC-4: "켜기"를 누르면 소리가 약 0.3초에 걸쳐 커지고, 다시 누를 때까지 계속 울린다. 버튼 글자는 "끄기"로 바뀐다. "끄기"를 누르면 약 0.3초에 걸쳐 작아지며 멈춘다. (딸깍 소리 없이)
- [ ] AC-5: 울리는 중에 음·높이·울림을 바꾸면 멈추지 않고 새 소리로 바뀐다. 음량 막대(0~100)는 울리는 중에도 바로 적용된다.
- [ ] AC-6: 메트로놈과 기준음을 동시에 켤 수 있고, 하나를 꺼도 다른 하나는 계속 울린다.
- [ ] AC-7: 다른 탭으로 옮기면 기준음이 멈춘다 (메트로놈과 같은 방식).
- [ ] AC-8: 소리는 음원 파일 없이 브라우저가 직접 만든다 (Web Audio API). 인터넷 없이도 켜진다.
- [ ] AC-9: 설정(음, 높이, 울림, 음량)은 localStorage `muselog-drone`에 저장되어 새로고침 뒤에도 그대로다. 저장값이 없거나 깨진 항목은 기본값(라 A, 보통, 근음만, 음량 60)으로 읽는다.
- [ ] AC-10: `muselog-drone`이 `BACKUP_KEYS`에 들어가 백업·계정 동기화에 함께 담긴다 (13개). `CLAUDE.md` 키 표와 개인정보처리방침의 저장 항목 목록("메트로놈 설정" 옆)에 "기준음 설정"이 추가된다.
- [ ] AC-11: 휴대폰 너비(360px)에서 카드가 가로로 넘치지 않는다.
- [ ] AC-12: `npm test`, `npm run build`, `npm run lint`가 오류 없이 끝난다.

## 비범위

- 연습 기록에 저장하기 (기준음은 시간을 재지 않는다. 시간 기록은 연습 타이머로)
- 악기 소리 고르기(피아노·현악 음원 등). 이번에는 부드러운 전자음 한 가지
- 기준 A4를 440 말고 다른 값(442 등)으로 바꾸기
- 7화음, 직접 음 여러 개 고르기
- 휴대폰 화면이 꺼지거나 앱을 내렸을 때 계속 울리기 (브라우저가 멈출 수 있음)
- 튜너와 묶어 "드론에 맞춰 부른 음이 맞는지" 보여 주기

## 확인 방법

- 자동: `npm test`, `npm run build`, `npm run lint`
- 수동 (브라우저):
  1. `npm run dev` 실행 후 http://localhost:5173/ 열기
  2. 작업실 탭 → 기준음 카드에서 음을 고르고 "켜기" → 소리가 계속 나는지, 음을 바꾸면 끊김 없이 바뀌는지
  3. 메트로놈도 켜서 둘이 함께 울리는지, 다른 탭으로 가면 기준음이 멈추는지
  4. 새로고침 후 설정이 그대로인지
  5. 휴대폰 너비에서 카드 모양 확인
