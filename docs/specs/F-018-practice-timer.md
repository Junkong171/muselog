# F-018: 지금 연습 시작 타이머

- 상태: 구현됨
- 작성일: 2026-11-03
- 관련 파일: `src/PracticeTimer.jsx`(새로), `src/lib/timer.js`(새로), `src/lib/timer.test.js`(새로), `src/App.jsx`, `src/App.css`, `CLAUDE.md`

## 목적

연습을 시작하기까지의 문턱을 낮춘다. 어느 탭에서든 버튼 하나로 시간을 재기 시작하고, 쉬는 시간은 빼고 잰 연습 시간을 끝날 때 연습 기록으로 남긴다.

## 사용자 시나리오

1. 어느 탭에서든 "지금 연습 시작"을 누른다. 곡을 고르지 않아도 바로 시간이 올라간다.
2. 잠깐 쉴 때 "휴식"을 누른다. 연습 시간은 멈추고 휴식 시간이 올라간다.
3. "다시 시작"을 누르면 연습 시간이 이어서 올라간다.
4. 다 하면 "연습 종료"를 누르고, 곡과 메모를 적어 저장한다.

## 수용 기준

### 시작
- [ ] AC-1: 8개 탭 모두에서 위쪽 바 아래에 타이머 줄이 보이고, 처음에는 "지금 연습 시작" 버튼이 있다.
- [ ] AC-2: 버튼을 누르면 곡이나 메모를 묻지 않고 바로 연습 시간이 `00:00:00`부터 1초마다 올라간다. "휴식"과 "연습 종료" 버튼이 보인다.

### 휴식
- [ ] AC-3: "휴식"을 누르면 연습 시간이 멈추고 "휴식 중"과 휴식 시간이 올라가며, 버튼은 "다시 시작"과 "연습 종료"로 바뀐다.
- [ ] AC-4: "다시 시작"을 누르면 멈췄던 연습 시간에서 이어서 올라간다. 휴식 시간은 연습 시간에 더해지지 않는다. 휴식을 여러 번 해도 같다.

### 종료와 저장
- [ ] AC-5: 연습 중이나 휴식 중에 "연습 종료"를 누르면 시간이 멈추고 저장 칸이 보인다. 곡 선택(처음 값 "자유 연습"), 연습 시간(분, 1~600, 잰 시간이 채워져 있고 고칠 수 있음), 메모, "기록 저장", "계속하기", "버리기"가 있다.
- [ ] AC-6: "기록 저장"을 누르면 연습 기록 탭에 새 기록이 생기고, 오늘의 연습과 이번 주 연습이 그만큼 늘며, 타이머 줄은 처음 상태로 돌아간다. 메모가 비어 있으면 연습 기록 탭처럼 "연습 내용 미입력"으로 저장된다. 분이 1~600 밖이면 저장되지 않고 안내 문구가 보인다.
- [ ] AC-7: "계속하기"를 누르면 종료를 누르기 전 상태(연습 중 또는 휴식 중)로 돌아가고, 저장 칸에 있던 시간도 그동안 흐른 것으로 친다.
- [ ] AC-8: "버리기"는 확인 창을 띄운 뒤, 기록을 남기지 않고 타이머를 처음 상태로 돌린다.
- [ ] AC-9: 잰 시간이 1분보다 짧으면 저장 칸의 연습 시간은 1분으로 채워진다. 그 밖에는 메트로놈의 `elapsedToMinutes`와 같은 방식으로 분으로 바꾼다.

### 계속 재기
- [ ] AC-10: 재는 중에 탭을 옮겨도 타이머가 멈추지 않고 이어진다.
- [ ] AC-11: 시작 시각을 기준으로 계산하므로, 브라우저 탭이 뒤로 가거나 휴대폰 화면이 꺼졌다 돌아와도 지나간 시간이 그대로 반영된다.
- [ ] AC-12: 새로고침하거나 브라우저를 다시 열어도 연습 중·휴식 중 상태와 시간이 이어진다. 저장 칸을 열어 둔 상태에서 새로고침하면 종료를 누르기 전 상태로 돌아간다.
- [ ] AC-13: 저장된 타이머 값이 깨져 있거나 시계가 거꾸로 가서 계산이 음수가 되어도 앱은 멈추지 않는다. 깨진 값은 처음 상태로, 음수는 0으로 읽는다.

### 공통
- [ ] AC-14: 재는 동안 메트로놈, 튜너, 영감 탭 들어보기를 평소처럼 쓸 수 있다. 메트로놈의 시간 재기와 "연습 기록에 저장"은 그대로이고 타이머와 연결되지 않는다.
- [ ] AC-15: 폭 700px 이하에서 타이머 줄과 저장 칸이 화면 밖으로 넘치지 않는다(페이지 가로 스크롤 없음).
- [ ] AC-16: 다른 탭의 기존 기능이 이전과 똑같이 동작한다. 연습 기록 탭의 직접 입력도 그대로다.
- [ ] AC-17: `src/lib/timer.test.js`가 시작, 휴식, 다시 시작, 휴식 여러 번, 시간을 분으로 바꾸기, 깨진 값 읽기, 음수 처리를 검사하고, `npm test`, `npm run build`, `npm run lint`가 오류 없이 끝난다.

## 비범위

- 목표 시간이 되면 소리나 알림 주기, 정해진 시간만큼 재는 카운트다운(뽀모도로)
- 메트로놈 시간과 합치기 (메트로놈과 타이머를 둘 다 저장하면 기록이 두 번 남는다. 이번에는 바꾸지 않는다)
- 여러 브라우저 탭이나 기기 사이에서 타이머 맞추기 (계정 동기화에 넣지 않는다)
- 휴식 시간을 기록에 남기기나 통계로 보여 주기
- 자정을 넘긴 연습을 두 날로 나누기 (저장한 시각의 날짜로 기록된다)
- 재는 동안 곡 고르기 (곡은 종료할 때 고른다)

## 데이터 영향

| 항목 | 내용 |
|---|---|
| 사용하는 localStorage 키 | `muselog-timer` (새로, 읽기/쓰기, 이 기기 전용). `muselog-logs`, `muselog-minutes` (기존 저장 함수 `recordPractice`로 쓰기) |
| 데이터 구조 변경 | 새 키만 추가. `muselog-timer` = `{ status("running"/"resting"), since(시각 숫자), practiceMs, restMs }`, 재고 있지 않으면 키 없음. 기존 키 구조는 그대로 |
| 백업·동기화 | 넣지 않는다. 기록이 아니라 지금 재는 중인 상태이기 때문이다(`muselog-sync-meta`와 같은 이유). `BACKUP_KEYS`는 12개 그대로. 저장된 연습 기록은 지금처럼 백업·동기화된다 |
| 마이그레이션 | 필요 없음. 키가 없으면 처음 상태 |
| 개인정보처리방침 | 바꾸지 않음. 타이머 값은 기기 밖으로 나가지 않고, 저장되는 기록은 이미 있는 연습 기록 항목이다 |

- 자동: `npm test`, `npm run build`, `npm run lint`
- 수동 (브라우저):
  1. `npm run dev` 실행 후 http://localhost:5173/ 열기
  2. "지금 연습 시작", 탭 옮기기, "휴식", "다시 시작"을 차례로 눌러 시간이 맞는지 본다
  3. 재는 중과 휴식 중에 각각 새로고침한다
  4. "연습 종료"에서 "계속하기", "버리기", "기록 저장"을 각각 해 보고 연습 기록 탭과 오늘의 연습을 본다
  5. 폭 700px, 375px, 320px에서 본다
