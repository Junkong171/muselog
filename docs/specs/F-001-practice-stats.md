# F-001: 연습 통계 탭

- 상태: 구현됨 (현재 동작을 역으로 문서화)
- 작성일: 2026-10-23
- 관련 파일: `src/App.jsx` (통계 계산 104–124줄, 화면 288–373줄), `src/lib/stats.js`, `src/lib/stats.test.js`, `src/App.css`

## 목적

쌓인 연습 기록(`muselog-logs`)으로 총 연습 시간, 연속 연습 일수, 이번 주 흐름, 곡별 연습 시간을 한 화면에서 보여준다.

## 사용자 시나리오

1. 사용자가 왼쪽 메뉴에서 "연습 통계"를 누른다.
2. 요약 카드 4개, "이번 주 연습 시간" 막대그래프, "곡별 연습 시간" 순위가 보인다.
3. "연습 기록" 탭에서 기록을 추가하거나 삭제하면, 다시 통계 탭에 왔을 때 숫자가 바뀌어 있다.

## 수용 기준

### 요약 카드 (`src/App.jsx` 298–319줄)

- [ ] AC-1: 제목 "연습 통계"와 카드 4개가 이 순서로 보인다: "총 연습 시간", "연속 연습", "이번 주 연습한 날", "연습한 날 평균".
- [ ] AC-2: "총 연습 시간"은 모든 기록의 `minutes` 합계를 "분" 단위로 보여준다. 기록이 없으면 0분이다.
- [ ] AC-3: "연속 연습"은 오늘부터 하루씩 거슬러 올라가며 기록이 있는 날이 이어진 일수를 "일" 단위로 보여준다. 오늘 기록이 없으면 어제부터 센다. 하루라도 비면 거기서 끊긴다.
- [ ] AC-4: 연속 연습이 1일 이상이면 "꾸준히 이어가는 중이에요", 0일이면 "오늘 연습하면 시작돼요"가 보인다.
- [ ] AC-5: "이번 주 연습한 날"은 이번 주(월요일 시작) 7일 중 기록이 있는 날 수를 "n / 7일"로 보여준다.
- [ ] AC-6: "연습한 날 평균"은 총 연습 시간 ÷ 기록이 있는 날 수(전체 기간)를 반올림한 값이다. 기록이 없으면 0분이다.

### 이번 주 연습 시간 그래프 (`src/App.jsx` 321–347줄)

- [ ] AC-7: 머리글에 "총 {이번 주 합계}분 · 목표 {하루 목표}분"이 보인다.
- [ ] AC-8: 막대 7개와 아래 요일 표시가 "월 화 수 목 금 토 일" 순서로 보인다. 이번 주는 오늘이 속한 주의 월요일부터 일요일까지다.
- [ ] AC-9: 기록이 있는 날의 막대 위에 분 숫자가 보이고, 막대 높이는 그 날 분에 비례한다. 기록이 없는 날은 숫자 없이 4px 높이의 연한 막대(`.bar.zero`)로 보인다.
- [ ] AC-10: 오늘 막대는 진한 색(`.bar.today`)이고, 오늘 요일 글자는 굵게(`.week-labels .today`) 보인다.
- [ ] AC-11: "목표 {하루 목표}분" 가로선이 보인다. 그래프의 최댓값은 max(하루 목표, 이번 주 하루 최대 분, 1) × 1.15이다.

### 곡별 연습 시간 (`src/App.jsx` 349–372줄)

- [ ] AC-12: 머리글에 "곡별 연습 시간"과 "누적 기준"이 보인다.
- [ ] AC-13: 곡별 누적 분이 많은 순서로 "곡 이름 · 막대 · n분" 행이 보인다. 가장 많은 곡의 막대가 100% 너비이고, 나머지는 그에 비례한다.
- [ ] AC-14: 곡 이름이 없는 기록(빈 문자열 또는 필드 없음)은 "자유 연습" 한 행으로 합쳐진다.
- [ ] AC-15: 기록이 하나도 없으면 "연습 기록을 남기면 곡별 통계가 보여요."가 보인다.

### 날짜 기준과 자동 검사

- [ ] AC-16: 날짜는 브라우저의 로컬 시간대 기준 "YYYY-MM-DD"로 묶는다 (`src/lib/stats.js`의 `dateKey`).
- [ ] AC-17: `npm test`가 통과한다 (`src/lib/stats.test.js` 10개 테스트).
- [ ] AC-18: `npm run build`가 오류 없이 끝난다.

## 비범위

- 기간 선택(지난주, 월별 등), 그래프 확대, 데이터 내보내기: 현재 없음
- 모든 탭 위쪽에 공통으로 보이는 카드 3개(오늘의 연습 / 이번 주 연습 / 하루 목표): 이 명세에서 다루지 않음
- `muselog-minutes` 값: 통계 계산에 쓰이지 않음 (통계는 모두 `muselog-logs`에서 계산)

## 확인 방법

- 자동: `npm test`, `npm run build`, `npm run lint`
- 수동 (브라우저):
  1. `npm run dev` 실행 후 http://localhost:5173/ 열기
  2. "연습 기록" 탭에서 곡을 고르지 않고 15분, 곡을 골라 30분 기록을 저장한다.
  3. "연습 통계" 탭에서 총 연습 시간 45분, 연속 연습 1일, 이번 주 연습한 날 1 / 7일, 평균 45분인지 본다.
  4. 오늘 요일 막대가 진한 색이고 위에 45가 보이는지 본다.
  5. 곡별 연습 시간에 고른 곡 30분이 첫 행, "자유 연습" 15분이 둘째 행인지 본다.
  6. 저장한 기록 2개를 삭제해 원래 상태로 돌린다.
