# F-021: 메트로놈과 타이머 기록 겹침 막기

- 상태: 구현됨
- 작성일: 2026-11-05
- 관련 파일: `src/Metronome.jsx`, `src/PracticeTimer.jsx`, `src/App.jsx`

## 목적

같은 연습 시간이 연습 타이머와 메트로놈에 함께 쌓여 두 번 기록되는 것을 막는다. 타이머를 쓰는 동안에는 타이머 기록 하나만 남긴다. 그래야 통계의 연습 시간이 실제보다 부풀지 않는다.

## 사용자 시나리오

1. "지금 연습 시작"을 누르고 작업실에서 메트로놈을 켠다.
2. 메트로놈 소리는 평소처럼 나고, 메트로놈의 "연습 기록에 저장" 자리에는 타이머로 저장한다는 안내가 보인다.
3. "연습 종료"에서 저장하면 기록이 하나만 남는다.

## 수용 기준

### 타이머가 재는 동안
- [ ] AC-1: 타이머가 연습 중, 휴식 중, 저장 칸을 연 상태이면 메트로놈의 "이번 연습 시간"이 늘지 않는다.
- [ ] AC-2: 이때 메트로놈의 "연습 기록에 저장" 버튼과 곡 선택 대신 "타이머가 재는 중이에요. 연습 종료에서 저장해 주세요." 안내가 보인다. "1분 이상 연습하면 저장할 수 있어요." 안내는 보이지 않는다.
- [ ] AC-3: 메트로놈 소리, 시작·정지, BPM, 박자, 강조, 리듬, 탭은 타이머와 상관없이 평소처럼 동작한다. 타이머를 켜거나 끌 때 메트로놈 소리가 멈추지 않는다.

### 타이머 앞뒤의 메트로놈 시간
- [ ] AC-4: 타이머를 시작하기 전에 메트로놈으로 쌓은 시간은 지워지지 않고 그대로 멈춰 있다. 타이머를 저장하거나 버려서 끝나면 그 시간부터 다시 늘고, 1분 이상이면 "연습 기록에 저장"으로 저장할 수 있다.
- [ ] AC-5: 메트로놈을 켠 채 타이머를 시작하면 그 순간부터 시간이 멈추고, 타이머가 끝난 순간부터 다시 늘어난다. 타이머가 재는 동안의 시간은 메트로놈 기록에 들어가지 않는다.
- [ ] AC-6: 타이머를 쓰지 않으면 메트로놈의 시간 재기와 "연습 기록에 저장"이 이전과 똑같이 동작한다. 저장한 기록의 메모(BPM 등)도 그대로다.

### 예시
- [ ] AC-7: 메트로놈을 켠 채 타이머를 시작해 재고 "기록 저장"을 누르면, 그 시간의 기록은 타이머 기록 1개만 남는다.
- [ ] AC-8: 재는 중에 새로고침하면 타이머가 이어지고, 앱은 지금처럼 대시보드로 열린다. 이때 작업실 탭을 다시 열면 메트로놈 저장 자리에 AC-2의 안내가 보인다.

### 공통
- [ ] AC-9: 연습 타이머의 시작, 휴식, 종료, 저장과 휴식 알림, 다른 탭의 기능이 이전과 똑같이 동작한다.
- [ ] AC-10: 폭 700px 이하에서 AC-2의 안내가 화면 밖으로 넘치지 않는다(페이지 가로 스크롤 없음).
- [ ] AC-11: `npm test`, `npm run build`, `npm run lint`가 오류 없이 끝난다.

## 비범위

- 이미 저장된 겹친 기록을 찾아 고치거나 합치기 (어느 쪽이 겹친 것인지 알 수 없다. 연습 기록 탭에서 직접 지울 수 있다)
- 타이머 없이 메트로놈 저장 기능을 없애기
- 타이머 기록에 메트로놈 BPM을 자동으로 적기
- 연습 기록 탭의 직접 입력과 겹치는지 검사하기

## 데이터 영향

| 항목 | 내용 |
|---|---|
| 사용하는 localStorage 키 | `muselog-timer`, `muselog-logs`, `muselog-minutes`, `muselog-metronome` (기존과 같음) |
| 데이터 구조 변경 | 없음. 메트로놈이 쌓은 시간은 지금처럼 저장하지 않고 화면이 켜져 있는 동안만 기억한다 |
| 마이그레이션 | 필요 없음. 이미 저장된 기록은 바꾸지 않는다 |
| 개인정보처리방침 | 바꾸지 않음. 모으거나 내보내는 정보가 없다 |

## 확인 방법

- 자동: `npm test`, `npm run build`, `npm run lint`
- 수동 (브라우저):
  1. `npm run dev` 실행 후 http://localhost:5173/ 열기
  2. 작업실에서 메트로놈만 1분 이상 재고 저장한다 (이전과 같은지)
  3. 메트로놈을 켠 채 "지금 연습 시작"을 눌러 시간이 멈추고 안내가 보이는지, 소리가 끊기지 않는지 본다
  4. "연습 종료"에서 저장한 뒤 기록이 하나인지, 메트로놈 시간이 다시 늘어나는지 본다
  5. 재는 중에 새로고침한다
  6. 폭 700px, 375px, 320px에서 본다
