# F-035: 캘린더 일정 수정

- 상태: 구현됨
- 작성일: 2026-11-17
- 관련 파일: `src/App.jsx`, `src/lib/calendar.js`, `src/lib/calendar.test.js`

## 목적

지금은 저장한 일정에 "삭제" 버튼만 있어서, 시간이나 제목을 바꾸려면 지우고 새로 써야 한다. 저장한 일정을 그 자리에서 고칠 수 있게 한다. (연습 기간 메모 F-016의 "수정" 방식과 같게 맞춘다)

## 사용자 시나리오

1. 캘린더 탭에서 일정이 있는 날을 누른다.
2. 아래 일정 목록에서 고치고 싶은 일정의 "수정" 버튼을 누른다.
3. 위쪽 입력 칸에 그 일정의 제목·시간·메모가 채워지고, 제목이 "○월 ○일 일정 수정"으로 바뀐다.
4. 내용을 고치고 "수정 저장"을 누르면 그 일정이 바뀐다. (새 일정이 하나 더 생기지 않는다)
5. 그만두려면 "취소"를 누른다. 입력 칸이 비워지고 원래 일정은 그대로 남는다.

## 수용 기준

- [ ] AC-1: 캘린더 탭에서 고른 날의 일정 목록 각 줄에 "수정" 버튼이 "삭제" 버튼 옆에 보인다.
- [ ] AC-2: "수정"을 누르면 입력 칸에 그 일정의 제목, 시·분(종일이면 빈 칸), 메모가 채워지고, 카드 제목이 "(날짜) 일정 수정", 저장 버튼 글자가 "수정 저장"으로 바뀌며 "취소" 버튼이 보인다.
- [ ] AC-3: 내용을 고쳐 "수정 저장"을 누르면 그 일정의 제목·시간·메모만 바뀌고, 일정 개수는 그대로이며, id도 그대로다. 저장 뒤 입력 칸은 비워지고 "일정 추가" 상태로 돌아간다.
- [ ] AC-4: 수정 중에 달력에서 다른 날을 누르고 "수정 저장"을 누르면 그 일정이 새로 고른 날로 옮겨진다. (카드 제목에 고른 날짜가 보여 어디에 저장될지 알 수 있다)
- [ ] AC-5: "취소"를 누르면 입력 칸이 비워지고, 원래 일정은 바뀌지 않는다.
- [ ] AC-6: 제목을 비우거나 시간이 잘못되면(예: 25시) 수정 저장이 되지 않고, 잘못된 시간이면 지금과 같은 안내 문구가 보인다. 원래 일정은 그대로다.
- [ ] AC-7: 수정 중인 일정을 "삭제"하면 일정이 지워지고 입력 칸도 "일정 추가" 상태로 돌아간다.
- [ ] AC-8: 저장된 시간 문자열을 시·분 칸으로 나누는 순수 함수(`splitTime`, 예: "09:05" → ["09", "05"], "" → ["", ""], 깨진 값 → ["", ""])가 `src/lib/calendar.js`에 있고 테스트가 있다.
- [ ] AC-9: 일정 추가·삭제, 다가오는 일정, 대시보드 D-DAY, 연습 기간 메모 수정 등 기존 동작은 그대로다.
- [ ] AC-10: `npm test`, `npm run build`, `npm run lint`가 오류 없이 끝난다.

## 비범위

- 대시보드·"다가오는 일정" 목록에서 바로 수정하기 (고른 날의 목록에서만 수정)
- 반복 일정, 알림
- 삭제 확인 창 추가 (지금처럼 바로 삭제)

## 확인 방법

- 자동: `npm test`, `npm run build`, `npm run lint`
- 수동 (브라우저):
  1. `npm run dev` 실행 후 http://localhost:5173/ 열기
  2. 캘린더 탭에서 날짜를 골라 일정 "레슨 14:00"을 저장한다.
  3. "수정"을 눌러 시간을 15:30, 제목을 "보컬 레슨"으로 바꾸고 "수정 저장" → 목록에 하나만, 바뀐 내용으로 보이는지 확인
  4. 다시 "수정" → 다른 날을 누르고 "수정 저장" → 일정이 그 날로 옮겨졌는지 확인
  5. "수정" → "취소" → 일정이 그대로인지 확인
