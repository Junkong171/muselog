# F-028: 작업실 코드표·스케일표

- 상태: 구현됨
- 작성일: 2026-11-07
- 관련 파일: 새 파일 `src/ChordChart.jsx`, `src/lib/chordChart.js`, `src/lib/chordChart.test.js`, `src/useChordPlayer.js`(한 음 길이를 정할 수 있게), `src/App.jsx`(작업실에 카드 추가), `src/App.css`, `public/licenses.html`(음원 쓰는 곳에 작업실 추가), `CLAUDE.md`(파일 목록)

## 목적

코드 구성음이나 스케일(음계)이 헷갈릴 때 책이나 다른 앱을 찾지 않고 작업실에서 바로 보고 들을 수 있게 한다.

## 사용자 시나리오

1. 작업실 탭 맨 아래 **"코드표·스케일표"** 카드에서 **코드 / 스케일** 중 하나를 고른다.
2. 근음(C~B 12개)과 종류(예: m7, 내추럴 마이너)를 고른다.
3. 카드에 이름(예: "Am7"), 구성음 이름(예: A · C · E · G), 피아노 건반 그림에 그 음들이 색칠되어 보인다.
4. **"들어보기"**를 누르면 피아노 소리로 코드는 한꺼번에, 스케일은 한 음씩 차례로 울리고, 울리는 음의 건반이 강조된다.

## 수용 기준

- [ ] AC-1: 작업실 탭의 튜너 카드 아래에 제목 "코드표·스케일표" 카드가 있고, "코드" / "스케일" 버튼으로 둘 중 하나를 고른다. 처음에는 "코드", 근음 C, 첫 번째 종류가 골라져 있다.
- [ ] AC-2: 근음은 C, Db, D, Eb, E, F, F#, G, Ab, A, Bb, B 12개다 (영감 탭의 조 이름과 같다). 각 버튼에 계이름(도, 레♭ …)도 작게 보인다.
- [ ] AC-3: 코드 종류는 12가지다: 메이저(기호 없음), m, 7, maj7, m7, 6, sus2, sus4, add9, dim, aug, m7b5. 구성음(근음에서 몇 반음 위)은 각각 0·4·7 / 0·3·7 / 0·4·7·10 / 0·4·7·11 / 0·3·7·10 / 0·4·7·9 / 0·2·7 / 0·5·7 / 0·4·7·14 / 0·3·6 / 0·4·8 / 0·3·6·10 이다.
- [ ] AC-4: 스케일 종류는 6가지다: 메이저(장음계), 내추럴 마이너(단음계), 하모닉 마이너, 메이저 펜타토닉, 마이너 펜타토닉, 블루스. 구성음은 각각 0·2·4·5·7·9·11 / 0·2·3·5·7·8·10 / 0·2·3·5·7·8·11 / 0·2·4·7·9 / 0·3·5·7·10 / 0·3·5·6·7·10 이다.
- [ ] AC-5: 카드에 코드 이름(근음 + 종류 기호, 예: "Am7", "C", "F#dim")과 구성음 이름이 낮은 음부터 보인다. 구성음 이름은 음악 이론에 맞는 글자를 쓴다 (예: Eb m → Eb · Gb · Bb, E 메이저 → E · G# · B, F 메이저 스케일 → F · G · A · Bb · C · D · E). 같은 글자에 #·b가 두 개 붙어야 하는 경우(예: Db dim의 Abb)만 가까운 보통 이름(G)으로 바꾼다.
- [ ] AC-6: 피아노 건반 그림(C4부터 D6까지, 흰 건반 16개)에 구성음이 색칠된다. 코드는 근음이 C4~B4 사이에 오도록 쌓고, 스케일은 근음부터 한 옥타브 위 근음까지 보여 준다.
- [ ] AC-7: "들어보기"를 누르면 그랜드 피아노 음원으로 코드는 모든 음이 함께 약 2초, 스케일은 한 음씩 약 0.4초 간격으로 올라가며 울린다. 울리는 동안 버튼은 "정지"가 되고, 스케일은 지금 나는 음의 건반이 따로 강조된다. 소리가 끝나거나 "정지"를 누르면 멈춘다.
- [ ] AC-8: 근음·종류·코드/스케일을 바꾸거나 다른 탭으로 가면 소리가 멈춘다. 음원을 받지 못하면 "소리를 불러오지 못했어요. 인터넷 연결을 확인하고 다시 눌러 주세요."가 보인다.
- [ ] AC-9: 카드 아래에 영감·수첩 탭과 같은 음원 출처 한 줄(FluidR3 GM, CC BY 3.0)이 보이고, `public/licenses.html`의 음원 쓰는 곳에 "작업실 코드표·스케일표"가 추가된다.
- [ ] AC-10: 필요한 음원 파일이 모두 있다: 모든 근음 × 모든 코드·스케일 종류의 음이 `public/sounds/acoustic_grand_piano/`에 있는지 자동 테스트로 확인한다.
- [ ] AC-11: 영감·수첩 탭의 코드 들어보기는 전과 같이 코드 하나에 2초씩 울린다 (`useChordPlayer`를 바꾼 뒤에도).
- [ ] AC-12: 휴대폰 너비(360px)에서 카드와 건반 그림이 가로로 넘치지 않는다.
- [ ] AC-13: `npm test`, `npm run build`, `npm run lint`가 오류 없이 끝난다.

- 수동 (브라우저):
