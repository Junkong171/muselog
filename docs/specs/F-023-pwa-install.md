# F-023: 휴대폰 홈 화면에 앱처럼 설치하기 (PWA)

- 상태: 구현됨
- 작성일: 2026-11-06
- 관련 파일: `index.html`, `src/main.jsx`, `public/manifest.webmanifest`(새 파일), `public/sw.js`(새 파일), `public/icons/`(새 폴더)

## 목적

연습할 때 브라우저에서 주소를 찾지 않고 홈 화면 아이콘 하나로 바로 열게 한다. 앱을 여러 개 오가다 연습을 건너뛰는 일을 줄이고, 인터넷이 약한 연습실에서도 쓸 수 있게 한다.

## 사용자 시나리오

1. 휴대폰 브라우저에서 사이트를 열고 메뉴의 "홈 화면에 추가"(또는 "앱 설치")를 누른다.
2. 홈 화면에 MUSELOG 아이콘이 생긴다.
3. 아이콘을 누르면 주소창 없이 전체 화면으로 앱이 열린다.
4. 인터넷이 없어도 전에 열어 본 앱이 열리고, 연습을 기록할 수 있다.

## 수용 기준

### 설치
- [ ] AC-1: 배포된 사이트가 `manifest.webmanifest`를 제공하고, 이름 MUSELOG, 시작 주소 `/`, 전체 화면 표시(`standalone`), 192px·512px 아이콘, 가장자리가 잘려도 되는 512px 아이콘(maskable)을 담는다.
- [ ] AC-2: 안드로이드 Chrome 또는 아이폰 Safari에서 홈 화면에 추가하면 MUSELOG 아이콘이 생기고, 누르면 주소창 없이 열린다.

### 인터넷 없이 쓰기
- [ ] AC-3: 한 번이라도 인터넷으로 연 뒤에는 인터넷이 끊겨도 앱이 열리고, 탭 8개를 오갈 수 있다.
- [ ] AC-4: 인터넷이 끊긴 상태에서 연습 기록과 타이머 저장이 되고, 다시 열어도 기록이 남아 있다.
- [ ] AC-5: 인터넷이 끊긴 상태에서 메트로놈이 동작한다.
- [ ] AC-6: 영감·수첩의 악기 소리는 전에 들어 본 음만 인터넷 없이 재생된다. 음원을 받지 못하면 앱이 멈추지 않고 지금과 같은 실패 안내가 보인다.
- [ ] AC-7: 로그인한 상태에서 인터넷이 끊기면 기록은 기기에 남고, 인터넷이 돌아온 뒤 앱을 다시 열면 계정에 저장된다.

### 새 버전과 기존 동작
- [ ] AC-8: 인터넷이 될 때 앱을 열면 항상 최신 배포 화면이 열린다. 옛 화면에 갇히지 않는다.
- [ ] AC-9: 임시 저장(캐시)은 이 사이트의 앱 파일과 음원만 담는다. Supabase 요청과 다른 사이트 요청은 저장하지 않고, 연습 기록은 지금처럼 localStorage에만 있다.
- [ ] AC-10: 기존 localStorage의 기록은 그대로 읽히고, 백업 키(`BACKUP_KEYS`)와 저장 형식은 바뀌지 않는다.
- [ ] AC-11: PC 브라우저에서 사이트로 쓰는 기능, 구글·카카오 로그인, 개인정보처리방침 페이지가 이전과 똑같이 동작한다.
- [ ] AC-12: 개발 서버(`npm run dev`)에서는 임시 저장을 켜지 않아, 고친 코드가 바로 보인다.
- [ ] AC-13: `npm test`, `npm run build`, `npm run lint`가 오류 없이 끝난다.

## 비범위

- 앱 안의 "설치하기" 버튼이나 설치 안내 창
- 푸시 알림, 백그라운드 동기화 (인터넷이 돌아오는 순간 자동 저장하지 않는다)
- 음원 190개를 미리 전부 받아 두기 (3.78MB. 들은 음만 저장한다)
- 앱 스토어 등록
- 기기 사이에 로그인 없이 기록 옮기기

## 알아 둘 제약

- **아이폰:** Safari와 홈 화면 앱은 저장 공간이 따로다. 로그인하지 않았다면 Safari의 기록이 홈 화면 앱에 보이지 않는다. 로그인하거나 백업 파일로 옮겨야 한다.
- **안드로이드:** Chrome과 설치한 앱이 저장 공간을 함께 쓴다.
- **로그인:** 홈 화면 앱 안에서 구글·카카오 로그인이 끝까지 되는지는 기기마다 다를 수 있어 실제 휴대폰으로 확인한다. 안 되면 원인을 보고하고 고칠 방법을 먼저 묻는다.
- **PC 시험의 한계:** AC-2와 로그인 흐름은 PC 브라우저로 확인할 수 없어 사용자가 휴대폰으로 확인한다.

## 데이터 영향

| 항목 | 내용 |
|---|---|
| 사용하는 localStorage 키 | 없음 (새 키 없음, 기존 키 그대로) |
| 데이터 구조 변경 | 없음. 브라우저 임시 저장 공간(Cache Storage)에 앱 파일과 음원만 저장한다 |
| 마이그레이션 | 필요 없음 |
| 개인정보처리방침 | 바꾸지 않음. 모으거나 내보내는 정보가 없고, 임시 저장에는 개인 기록이 들어가지 않는다 |

## 확인 방법

- 자동: `npm test`, `npm run build`, `npm run lint`
- 수동 (PC 브라우저): `npm run build` 후 `npm run preview`로 열고, 개발자 도구에서 오프라인으로 바꿔 AC-3~6과 AC-9를 본다
- 수동 (휴대폰, 배포 후): 홈 화면에 추가하고, 비행기 모드로 열어 보고, 로그인을 해 본다
