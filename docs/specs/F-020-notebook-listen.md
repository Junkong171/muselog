# F-020: 수첩에서 코드 다시 듣기

- 상태: 구현됨
- 작성일: 2026-11-05
- 관련 파일: `src/Notebook.jsx`, `src/Inspiration.jsx`, `src/useChordPlayer.js`(새로), `src/lib/inspiration.js`, `src/lib/inspiration.test.js`, `src/App.css`, `CLAUDE.md`

## 목적

수첩에 적어 둔 아이디어의 코드를 영감 탭으로 돌아가지 않고 바로 소리로 듣는다. 예전 아이디어의 분위기를 다시 떠올리기 쉽게 한다.

## 사용자 시나리오

1. 수첩 탭에서 코드가 함께 저장된 아이디어를 찾는다.
2. 카드 위쪽에서 악기를 고르고, 그 아이디어의 "들어보기"를 누른다.
3. 코드가 차례로 소리 나고 지금 나는 코드가 강조된다.

## 수용 기준

### 재생
- [ ] AC-1: 코드가 저장된 아이디어에 "들어보기" 버튼이 있다. 코드 없이 저장한 아이디어에는 버튼이 없다.
- [ ] AC-2: 수첩 탭에 악기 선택 칸(그랜드 피아노, 일렉 피아노, 나일론 기타, 통기타, 현악 합주)이 있고 처음 값은 그랜드 피아노다. 아이디어가 없으면 보이지 않는다.
- [ ] AC-3: "들어보기"를 누르면 그 아이디어의 코드가 차례로 한 번 소리 나고(코드 하나에 2초), 지금 나는 코드가 강조되며, 버튼은 "정지"로 바뀐다. 끝나거나 "정지"를 누르면 소리가 멈추고 강조가 사라지고 버튼이 돌아온다.
- [ ] AC-4: 음원을 받는 동안 버튼에 "불러오는 중…"이 보이고, 이때 누르면 취소된다. 받지 못하면 그 아이디어 아래에 한국어 안내가 보이고 버튼이 "들어보기"로 돌아오며 앱은 멈추지 않는다. 브라우저가 소리를 지원하지 않아도 한국어 안내가 보인다.
- [ ] AC-5: 한 번에 하나만 소리 난다. 재생 중에 다른 아이디어의 "들어보기"를 누르면 앞의 소리가 멈추고 새 아이디어가 시작된다.
- [ ] AC-6: 재생 중에 악기를 바꾸거나, 재생 중인 아이디어를 수정하거나 삭제하거나, 다른 탭으로 가면 소리가 멈춘다.

### 저장된 코드 읽기
- [ ] AC-7: 저장된 코드 이름에서 음을 읽는다. 영감 탭의 모든 진행을 12개 조로 낸 코드 이름을 읽은 결과가 영감 탭에서 내는 음과 모두 같다(`G/B`, `Bbmaj7`, `F#m7`, `E#` 포함).
- [ ] AC-8: 읽을 수 없는 코드 이름이 하나라도 있는 아이디어(손상된 백업 등)에는 "들어보기" 버튼이 없고, 글자와 코드는 지금처럼 보이며 앱은 멈추지 않는다.

### 공통
- [ ] AC-9: 영감 탭의 들어보기, 정지, 악기 선택, 불러오기 실패 안내가 이전과 똑같이 동작한다.
- [ ] AC-10: 수첩의 수정, 삭제, 목록 순서, 코드 글자(예: `C조 · C G Am F`)가 이전과 똑같이 보이고 동작한다. 수정은 여전히 메모 글자만 고친다.
- [ ] AC-11: 다른 탭과 연습 타이머가 이전과 똑같이 동작한다.
- [ ] AC-12: 폭 700px 이하에서 악기 선택 칸, 버튼, 코드 8개짜리 아이디어가 화면 밖으로 넘치지 않는다(페이지 가로 스크롤 없음).
- [ ] AC-13: `src/lib/inspiration.test.js`가 AC-7과 읽을 수 없는 코드 이름을 검사하고, `npm test`, `npm run build`, `npm run lint`가 오류 없이 끝난다.

## 비범위

- 수첩에서 코드나 조 바꾸기, 저장된 조와 다른 조로 듣기
- 코드 없이 저장한 아이디어에 코드 붙이기
- 반복 재생, 빠르기 조절
- 고른 악기를 다음 방문에 기억하기, 영감 탭과 악기 선택 맞추기
- 수첩 검색, 폴더·태그

## 데이터 영향

| 항목 | 내용 |
|---|---|
| 사용하는 localStorage 키 | `muselog-ideas` (읽기, 기존과 같음) |
| 데이터 구조 변경 | 없음. 저장된 코드 이름을 그대로 읽는다 |
| 마이그레이션 | 필요 없음. 지금까지 저장한 아이디어도 그대로 들을 수 있다 |
| 개인정보처리방침 | 바꾸지 않음. 모으거나 내보내는 정보가 없고, 음원은 앱에 포함된 파일이다 |

## 확인 방법

- 자동: `npm test`, `npm run build`, `npm run lint`
- 수동 (브라우저):
  1. `npm run dev` 실행 후 http://localhost:5173/ 열기
  2. 영감 탭에서 코드를 함께 저장하고, 코드 없이도 하나 저장한다
  3. 수첩 탭에서 "들어보기", "정지", 끝까지 듣기를 해 본다 (소리는 사용자가 귀로 확인)
  4. 재생 중 다른 아이디어 들어보기, 악기 변경, 수정, 삭제, 다른 탭으로 이동을 각각 해 본다
  5. 영감 탭의 들어보기가 그대로인지 본다
  6. 폭 700px, 375px, 320px에서 본다
