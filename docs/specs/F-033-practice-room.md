# F-033: 연습실 탭 (작업실 도구 나누기)

- 상태: 구현됨
- 작성일: 2026-11-08
- 관련 파일: `src/App.jsx`(연습실 탭 화면), `src/lib/tabs.js`(+ 테스트), 도구 파일 주석(`src/Tuner.jsx` 등), `public/privacy.html`, `public/licenses.html`, `CLAUDE.md`

## 목적

작업실 탭에 도구가 8개나 있어 원하는 도구를 찾기 어렵다. 음정·코드 연습 도구를 새 **연습실** 탭으로 나눠 탭마다 도구 수를 줄인다.

## 사용자 시나리오

1. 사이드바에서 **연습실**을 누르면 기준음, 튜너, 연습 녹음, 코드표·스케일표, 코드 전환 연습, 코드 분석이 보인다.
2. **작업실**을 누르면 오늘의 루틴, 메트로놈, 기준음, 연습 녹음이 보인다.
3. 어느 탭에서 기준음 설정을 바꾸거나 녹음해도 다른 탭에서 똑같이 보인다.

## 수용 기준

### 탭

- [ ] AC-1: 사이드바에 **연습실** 탭이 생기고, 기본 순서에서는 작업실 바로 앞에 있다 (대시보드 / 내 연습곡 / 연습 기록 / 연습 통계 / 캘린더 / 연습실 / 작업실 / 영감 / 수첩). 다른 탭처럼 아이콘이 있고 끌어서 순서를 바꿀 수 있다.
- [ ] AC-2: 사이드바 순서를 바꿔 저장해 둔 사용자도 연습실 탭이 보인다. 이때 연습실은 저장된 순서에서 작업실 바로 앞에 끼워진다. (작업실이 없는 깨진 저장값이면 맨 뒤.) 다른 탭의 순서는 그대로다.

### 화면 구성

- [ ] AC-3: 연습실 탭 위쪽에 제목 "연습실"과 짧은 설명이 있고, 작업실처럼 큰 요약 카드 대신 오늘·이번 주 연습 시간 한 줄 요약이 보인다.
- [ ] AC-4: 연습실 탭 카드 순서: 기준음(드론) → 튜너 → 연습 녹음 → 코드표·스케일표 → 코드 전환 연습 → 코드 분석.
- [ ] AC-5: 작업실 탭 카드 순서: 오늘의 루틴 → 메트로놈 → 기준음(드론) → 연습 녹음. 튜너, 코드표·스케일표, 코드 전환 연습, 코드 분석은 작업실에 없다.
- [ ] AC-6: 대시보드의 "오늘의 루틴" 카드의 "작업실 열기" 버튼은 그대로 작업실로 간다.

### 같은 설정·기록 함께 쓰기

- [ ] AC-7: 기준음 설정(`muselog-drone`)은 두 탭이 함께 쓴다. 작업실에서 음을 바꾸면 연습실에서도 바뀐 음이 보인다.
- [ ] AC-8: 연습 녹음 목록은 두 탭이 함께 쓴다. 한쪽에서 녹음하면 다른 탭에서도 그 녹음이 보인다.
- [ ] AC-9: 다른 탭으로 옮기면 지금 탭에서 나던 소리(기준음, 코드 전환 연습, 코드 들어보기)와 녹음이 멈춘다. (작업실 → 연습실, 연습실 → 작업실 모두)

### 문서·검사

- [ ] AC-10: 개인정보처리방침과 출처·라이선스 페이지의 "작업실 연습 녹음", "작업실 코드표·스케일표와 코드 분석" 같은 위치 설명이 새 위치에 맞게 바뀐다. CLAUDE.md의 탭 목록·파일 설명도 바뀐다.
- [ ] AC-11: 휴대폰 너비(360px)에서 탭 9개가 가로로 넘치지 않고 줄바꿈된다.
- [ ] AC-12: `npm test`(탭 순서 테스트 포함), `npm run build`, `npm run lint`가 오류 없이 끝난다.

## 비범위

- 도구 자체의 기능 변경
- 사용자가 직접 어느 탭에 어떤 도구를 둘지 고르기
- 메트로놈을 연습실에도 두기 (작업실에만 둔다)

## 데이터 영향

| 항목 | 내용 |
|---|---|
| 사용하는 localStorage 키 | `muselog-tab-order` (읽기 / 쓰기) |
| 데이터 구조 변경 | 없음. 탭 이름 목록에 "연습실"이 하나 늘어날 뿐 형식은 같다. 새 키 없음 |
| 마이그레이션 | 필요 없음. 예전 저장 순서에 "연습실"이 없으면 `normalizeTabOrder`가 작업실 앞에 끼워 읽는다. 예전 백업 파일도 그대로 불러온다. 기준음·코드 설정과 연습 녹음은 같은 키·저장소를 그대로 쓴다 |

## 확인 방법

- 자동: `npm test`, `npm run build`, `npm run lint`
- 수동 (브라우저):
  1. `npm run dev` 실행 후 http://localhost:5173/ 열기
  2. 사이드바에 연습실이 작업실 앞에 있는지, 두 탭의 카드 구성 확인
  3. 작업실에서 기준음 음 바꾸기 → 연습실에서 같은 음인지 확인
  4. 기준음을 켠 채 다른 탭으로 옮겨 소리가 멈추는지 확인
  5. 저장된 탭 순서가 있을 때(예: 작업실을 맨 위로 옮긴 뒤) 새로 열어 연습실이 작업실 바로 앞에 보이는지 확인
  6. 휴대폰 너비에서 사이드바 모양 확인
