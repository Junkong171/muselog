# F-017: 영감·수첩 탭 (키워드·코드 진행·아이디어 메모)

- 상태: 구현됨
- 작성일: 2026-11-03
- 관련 파일: `src/Inspiration.jsx`(새로), `src/Notebook.jsx`(새로), `src/lib/inspiration.js`(새로), `src/lib/inspirationData.js`(새로), `src/lib/inspiration.test.js`(새로), `src/lib/tabs.js`, `src/lib/tabs.test.js`, `src/lib/backup.js`, `src/lib/backup.test.js`, `src/lib/sync.js`, `src/lib/sync.test.js`, `src/App.jsx`, `src/App.css`, `public/privacy.html`, `CLAUDE.md`, `docs/ROADMAP.md`, `public/sounds/`(새로, 악기 음원)

## 목적

싱어송라이터가 곡을 쓰려고 할 때 막막함을 덜도록, 작사 키워드와 코드 진행을 뽑아 주고 소리로 들려주며, 떠오른 아이디어를 바로 적어 두는 공간을 만든다. AI나 서버 없이 앱에 넣어 둔 목록으로 동작한다.

## 사용자 시나리오

1. 사이드바에서 "영감" 탭을 연다.
2. "키워드 뽑기"를 누르면 단어 3개가 나온다. 마음에 드는 단어를 고정하고 나머지만 다시 뽑는다.
3. 장르·분위기·조를 고르면 코드 진행이 나온다. "다른 진행"으로 바꾸고, 악기를 고르고 "들어보기"로 소리를 듣는다.
4. 떠오른 가사 한 줄을 메모 칸에 적고 저장한다. 그때의 키워드와 코드가 함께 저장된다.
5. "수첩" 탭에서 예전 아이디어를 다시 보고, 고치거나 지운다.

## 수용 기준

### 탭
- [ ] AC-1: 사이드바 맨 끝에 "영감"(아이콘 ✦), "수첩"(아이콘 ✎) 탭이 생겨 탭이 8개가 된다. 탭 순서를 바꿔 저장해 둔 사용자도 기존 순서는 그대로이고 새 탭이 뒤에 붙는다. 끌어서 옮기기와 "기본 순서"도 8개로 동작한다.
- [ ] AC-2: 영감·수첩 탭 위쪽 통계는 작업실처럼 한 줄 요약으로 보인다.

### 키워드 뽑기
- [ ] AC-3: 처음 열면 키워드 3칸이 채워져 있다. 앞의 2칸은 구체적인 단어(장소·사물·시간 등, 100개 이상의 목록), 마지막 칸은 감정 단어(60개 이상의 목록)다. 세 단어는 서로 다르다.
- [ ] AC-4: 각 칸의 고정 버튼을 누르면 고정 표시가 켜지고, "키워드 뽑기"를 눌러도 고정한 단어는 바뀌지 않으며 고정하지 않은 칸만 바뀐다. 새로 뽑힌 단어는 직전 단어나 다른 칸 단어와 겹치지 않는다.

### 코드 진행
- [ ] AC-5: 장르(발라드, 인디 포크, R&B, 시티팝, 록), 분위기(밝음, 쓸쓸함, 몽환적), 조(C, Db, D, Eb, E, F, F#, G, Ab, A, Bb, B) 선택 칸이 있다. 처음 값은 발라드 / 밝음 / C다.
- [ ] AC-6: 장르·분위기 조합(15개)마다 코드 진행이 2개 이상 들어 있고, 고르면 4~8개 코드가 보인다. "다른 진행"을 누르면 같은 조합의 다음 진행으로 바뀌고, 끝에 닿으면 처음으로 돌아간다.
- [ ] AC-7: 조를 바꾸면 같은 진행이 그 조에 맞게 바뀐다. `I V vi IV`는 C조에서 `C G Am F`, G조에서 `G D Em C`, Eb조에서 `Eb Bb Cm Ab`이다.

### 들어보기
- [ ] AC-8: "들어보기"를 누르면 코드가 차례로 한 번 소리 나고(코드 하나에 2초), 지금 나는 코드가 강조되며, 버튼은 "정지"로 바뀐다. 끝나거나 "정지"를 누르면 소리가 멈추고 강조가 사라지고 버튼이 돌아온다.
- [ ] AC-9: 재생 중에 장르·분위기·조·진행을 바꾸거나 다른 탭으로 가면 소리가 멈춘다(바뀐 진행의 코드가 같아도). 브라우저가 소리를 지원하지 않으면 한국어 안내가 보이고 앱은 멈추지 않는다.
- [ ] AC-18: 악기 선택 칸에 그랜드 피아노, 일렉 피아노, 나일론 기타, 통기타, 현악 합주 5개가 있고 처음 값은 그랜드 피아노다. 소리는 실제 악기를 녹음한 음원(FluidR3)으로 나고, 재생 중에 악기를 바꾸면 소리가 멈춘다.
- [ ] AC-19: 음원은 앱과 함께 `public/sounds/`에 들어 있어 외부 사이트에서 받지 않는다. 고른 악기의 필요한 음만 "들어보기"를 누를 때 불러오며, 그동안 "불러오는 중"이 보인다. 불러오다 실패하면 한국어 안내가 보이고 버튼이 "들어보기"로 돌아오며 앱은 멈추지 않는다.
- [ ] AC-20: 15개 조합의 모든 진행을 12개 조에서 낼 때 필요한 음 파일이 5개 악기 모두에 있음을 자동 테스트가 검사한다.
- [ ] AC-21: 영감 탭에 음원 출처와 사용 조건이 보인다. 파일의 사용 조건은 구현 때 원본에서 다시 확인한다.

### 아이디어 메모
- [ ] AC-10: 메모 칸(1~500자, 필수)과 "아이디어 저장" 버튼, "키워드 함께 저장"·"코드 함께 저장" 체크(처음 값은 켜짐)가 있다. 비어 있으면 저장되지 않고 안내 문구가 보인다. 저장하면 메모 칸이 비워진다.
- [ ] AC-11: 영감 탭에는 목록 대신 "저장한 아이디어 N개"와 "수첩 열기" 버튼이 보이고, 누르면 수첩 탭으로 간다. 수첩 탭에는 저장한 아이디어가 최신순으로 전부 보인다. 아이디어가 없으면 안내 문구와 "영감 탭으로 가기" 버튼이 보인다. 각 줄에 메모, 저장 날짜, 함께 저장한 키워드와 코드(예: `C조 · C G Am F`)가 보이고 "수정"과 "삭제"가 있다. "수정"은 메모 글자만 고친다. "삭제"는 확인 창을 띄운 뒤 지운다.
- [ ] AC-12: 아이디어는 localStorage 키 `muselog-ideas`에 `[{ id, createdAt(ISO), text, keywords: [문자열], key(문자열, 코드 없으면 ""), chords: [문자열] }]`로 저장되어 새로고침 뒤에도 남는다. 깨진 값(배열 아님, 글자 없음)은 버리고, 빠진 항목은 기본값으로 읽는다. 키가 없으면 빈 목록이다.
- [ ] AC-13: `muselog-ideas`가 `BACKUP_KEYS`에 들어 있어 백업과 계정 동기화(자동 저장 감시 목록 포함)에 함께 담긴다. 아이디어만 있는 브라우저도 "기록 있음"으로 쳐서, 처음 로그인할 때 묻지 않은 채 덮어쓰지 않고, 어느 기록을 쓸지 묻는다(`isEmptyData`). "어느 기록을 쓸까요?" 창의 양쪽 요약에 연습 기간과 아이디어 개수도 보인다(`연습 기록 2개 · 연습곡 1곡 · 연습 기간 1개 · 아이디어 3개`).

### 공통
- [ ] AC-14: 개인정보처리방침의 계정에 저장하는 기록 목록과 열람·수정 문장에 "아이디어 메모"가 들어간다.
- [ ] AC-15: 화면 폭 700px 이하에서 8개 탭과 영감·수첩 탭 내용이 화면 밖으로 넘치지 않는다(페이지 가로 스크롤 없음).
- [ ] AC-16: 다른 6개 탭이 이전과 똑같이 동작한다.
- [ ] AC-22: 화면 폭 700px 이하에서 사이드바 탭이 세로로 쌓이지 않고 가로로 놓였다가 줄바꿈된다. 탭 끌어 옮기기 위치 계산도 이 가로 배치와 맞는다.
- [ ] AC-17: `src/lib/inspiration.test.js`가 키워드 뽑기(고정, 겹침 없음), 코드 변환(12개 조 모두 코드 이름 값까지), 조합별 진행 개수, 아이디어 정리를 검사하고, `npm test`, `npm run build`, `npm run lint`가 오류 없이 끝난다.

## 비범위

- 레퍼런스 곡을 넣어 비슷한 곡을 분석하는 기능: 다음 단계 (`docs/ROADMAP.md`에 기록)
- AI 추천, 서버, 사용자 단어·진행 직접 추가
- 단조(마이너 키) 선택: 조는 장조 이름으로 고르고, 쓸쓸한 분위기는 진행 안의 단화음으로 표현한다
- 반복 재생, 빠르기 조절, 코드표(손가락 위치), 인터넷이 끊겼을 때 재생하기(오프라인 저장)
- 수첩에서 검색, 폴더·태그로 나누기, 새 아이디어 바로 쓰기, 저장한 코드 다시 듣기
- 마지막으로 고른 장르·조·악기와 고정한 키워드를 다음 방문에 기억하기
- 실제 곡 제목이나 가사를 넣기 (단어와 진행은 직접 만든 일반적인 목록만 쓴다)

## 데이터 영향

## 확인 방법

- 자동: `npm test`, `npm run build`, `npm run lint`
- 수동 (브라우저):
  1. `npm run dev` 실행 후 영감 탭 열기 (음색은 사용자가 귀로 확인)
  2. 키워드 고정 후 다시 뽑기
  3. 장르·분위기·조 바꾸기, "다른 진행", "들어보기"와 "정지" (귀로 소리 확인은 사용자)
  4. 재생 중 다른 탭으로 이동해 소리가 멈추는지
  5. 영감 탭에서 아이디어 저장, "수첩 열기", 수첩에서 수정·삭제, 새로고침, 백업 파일에 `muselog-ideas`가 있는지
  6. 휴대폰 폭에서 확인
