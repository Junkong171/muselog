# F-031: 작업실 코드 전환 연습

- 상태: 구현됨
- 작성일: 2026-11-07
- 관련 파일: 새 파일 `src/ChordDrill.jsx`, 새 파일 `src/lib/chordDrill.js`(+ 테스트), `src/App.jsx`(작업실에 카드, 설정 저장·자동 저장 조건), `src/lib/backup.js`(+ 테스트), `src/App.css`, `public/privacy.html`, `CLAUDE.md`

## 목적

기타·피아노는 코드 모양을 알아도 박자에 맞춰 빨리 바꾸는 연습이 따로 필요하다. 정해진 박자마다 무작위 코드를 띄워, 다음 코드를 미리 보면서 바꾸는 연습을 작업실에서 바로 하게 한다.

## 사용자 시나리오

1. 작업실 탭 **"코드 전환 연습"** 카드에서 범위(전체 코드 / 조 안의 코드), 코드 종류, BPM, 몇 박마다 바꿀지를 고른다.
2. **"시작"**을 누르면 박 소리와 함께 지금 코드가 크게, 다음 코드가 작게 보인다.
3. 정한 박이 지나면 다음 코드가 지금 코드로 넘어오고 새 다음 코드가 뜬다. **"정지"**를 누르면 멈춘다.

## 수용 기준

- [ ] AC-1: 작업실 탭의 코드표·스케일표 카드 아래에 제목 "코드 전환 연습" 카드가 있다.
- [ ] AC-2: 범위 버튼 "전체" / "조 안에서"가 있다.
  - "전체": 근음 12개 × 고른 코드 종류(메이저 / m / 7 / maj7 / m7 중 여러 개, 적어도 하나는 켜져 있음)에서 뽑는다.
  - "조 안에서": 조(C~B 12개, 장조)를 고르고 "3화음" / "7화음"을 고르면 그 조의 다이아토닉 코드 7개(예: C조 3화음 C Dm Em F G Am Bdim, 7화음 Cmaj7 Dm7 Em7 Fmaj7 G7 Am7 Bm7b5)에서 뽑는다.
- [ ] AC-3: BPM(40~200, 기본 80, −/+ 버튼과 숫자 입력)과 바꾸는 간격 "2박 / 4박 / 8박"(기본 4박), 박 소리 켜기·끄기(기본 켜기)가 있다.
- [ ] AC-4: "시작"을 누르면 지금 코드(크게)와 다음 코드(작게, "다음: F")가 보이고, 박마다 점이 하나씩 채워진다. 박 소리를 켜면 박마다 소리가 나고 코드가 바뀌는 첫 박은 더 높은 소리가 난다.
- [ ] AC-5: 정한 박 수가 지나면 다음 코드가 지금 코드가 되고 새 다음 코드를 뽑는다. 같은 코드가 연달아 나오지 않는다.
- [ ] AC-6: "정지"를 누르면 소리와 바뀜이 멈춘다. 다른 탭으로 옮겨도 멈춘다. 연습 중에 설정을 바꾸면 다음 뽑기부터 새 설정을 쓴다.
- [ ] AC-7: 설정은 localStorage 키 `muselog-chord-drill`에 `{ scope("all"/"key"), types([...]), key("C"~"B"), sevenths(true/false), bpm, beats(2/4/8), click(true/false) }`로 저장되어, 다시 열어도 그대로다. 없거나 깨진 항목은 기본값("all" / ["maj","m"] / "C" / false / 80 / 4 / true)으로 읽는다.
- [ ] AC-8: `muselog-chord-drill`이 `BACKUP_KEYS`에 들어가 백업·계정 동기화에 함께 담기고, 이 설정만 바꿔도 로그인 상태에서 자동 저장된다. 개인정보처리방침의 저장 항목에 "코드 전환 연습 설정"이 추가되고 변경 이력이 적힌다.
- [ ] AC-9: 휴대폰 너비(360px)에서 카드가 가로로 넘치지 않고, 지금 코드 글자가 한눈에 읽힐 만큼 크다.
- [ ] AC-10: `npm test`, `npm run build`, `npm run lint`가 오류 없이 끝난다.

## 비범위

- 코드가 바뀔 때 코드 소리(피아노) 들려주기
- 기타 코드 운지 그림
- 단조 다이아토닉, 내가 고른 코드 목록만으로 연습하기
- 연습 시간을 연습 기록에 저장하기 (연습 타이머로)

## 데이터 영향

| 항목 | 내용 |
|---|---|
| 사용하는 localStorage 키 | 새 키 `muselog-chord-drill` (읽기 / 쓰기) |
| 데이터 구조 변경 | 새 키 추가. 기존 키는 그대로 |
| 마이그레이션 | 필요 없음 (키가 없으면 기본값). 예전 백업 파일에는 이 키가 없어도 불러오기가 그대로 된다 |

## 확인 방법

- 자동: `npm test`, `npm run build`, `npm run lint`
- 수동 (브라우저):
  1. `npm run dev` 실행 후 http://localhost:5173/ → 작업실 → 코드 전환 연습
  2. 범위·종류·BPM·간격을 바꿔 시작, 코드가 박에 맞춰 바뀌는지, 같은 코드가 연달아 안 나오는지 확인
  3. 새로고침 후 설정이 남는지, 다른 탭으로 가면 멈추는지 확인
  4. 휴대폰 너비에서 모양 확인
