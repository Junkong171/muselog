# F-022: 대시보드에 연속 연습일 표시

- 상태: 구현됨
- 작성일: 2026-11-05
- 관련 파일: `src/App.jsx`, `src/App.css`, `src/lib/stats.js`, `src/lib/stats.test.js`

## 목적

앱을 열자마자 며칠째 연습을 이어 가는지, 오늘 연습하면 며칠째가 되는지 보여 준다. 연속 기록이 끊기지 않게 하고 싶은 마음으로 오늘도 연습을 시작하게 하기 위해서다.

## 사용자 시나리오

1. 앱을 열면 대시보드 배너에 연속 연습 문구가 보인다.
2. 오늘 아직 연습하지 않았다면 "오늘 연습하면 며칠째"인지 보고 연습을 시작한다.
3. 연습을 기록하면 문구가 바로 오늘 기록이 들어간 내용으로 바뀐다.

## 수용 기준

### 문구
- [ ] AC-1: 대시보드 배너의 안내 글 아래에 연속 연습 문구가 한 줄 보인다.
- [ ] AC-2: 오늘 연습 기록이 있고 연속이 N일이면 "N일째 연습 중이에요. 오늘 연습 완료!"가 보인다.
- [ ] AC-3: 오늘 기록이 없고 어제까지 연속이 N일이면 "N일째 이어 가는 중이에요. 오늘 연습하면 N+1일째!"가 보인다. (N+1은 계산한 숫자로 보인다)
- [ ] AC-4: 오늘과 어제 모두 기록이 없으면 "오늘 연습하면 1일째가 시작돼요."가 보인다. 기록이 하나도 없을 때도 같다.

### 계산과 갱신
- [ ] AC-5: 연속 일수는 연습 통계 탭의 "연속 연습"과 항상 같은 숫자다.
- [ ] AC-6: 대시보드가 열린 채로 타이머에서 오늘 첫 기록을 저장하면, 새로고침 없이 AC-3의 문구가 AC-2의 문구로 바뀌고 숫자가 1 늘어난다.
- [ ] AC-7: 오늘의 기록을 모두 지우면 새로고침 없이 AC-3 또는 AC-4의 문구로 돌아간다.

### 범위와 화면
- [ ] AC-8: 이 문구는 대시보드 탭에만 보이고, 다른 탭의 화면은 바뀌지 않는다. 연습 통계 탭의 "연속 연습" 카드도 그대로다.
- [ ] AC-9: 폭 700px, 375px, 320px에서 문구가 잘리지 않고 필요하면 줄이 바뀌며, 페이지 가로 스크롤이 생기지 않는다.
- [ ] AC-10: 문구를 고르는 함수의 자동 테스트가 AC-2, AC-3, AC-4의 세 경우를 확인한다.
- [ ] AC-11: `npm test`, `npm run build`, `npm run lint`가 오류 없이 끝난다.

## 비범위

- 연속 기록이 끊겼을 때의 알림이나 경고
- 최장 연속 기록 저장, 뱃지 같은 보상
- 하루 목표를 채워야 연속으로 치는 규칙 (지금처럼 1분이라도 기록이 있으면 그날은 연속이다)
- 연속 일수 계산 방식 변경

## 확인 방법

- 자동: `npm test`, `npm run build`, `npm run lint`
- 수동 (브라우저):
  1. `npm run dev` 실행 후 http://localhost:5173/ 열기
  2. 기록이 없을 때, 어제까지만 있을 때, 오늘도 있을 때의 문구를 본다
  3. 대시보드를 연 채 타이머로 저장하고, 기록을 지워 문구가 바로 바뀌는지 본다
  4. 연습 통계 탭의 숫자와 비교한다
  5. 폭 700px, 375px, 320px에서 본다
