# F-014: 회원 탈퇴 (계정과 계정 기록 지우기)

- 상태: 구현됨
- 작성일: 2026-10-31
- 관련 파일: `docs/supabase/delete_account.sql`(새로), `src/App.jsx`, `src/App.css`, `CLAUDE.md`, `docs/ROADMAP.md`

## 목적

로그인한 사용자가 스스로 MUSELOG 계정과 서버에 저장된 기록(`user_data`)을 지울 수 있게 한다. (구글 앱 게시·개인정보처리방침에도 필요)

## 사용자 시나리오

1. 로그인한 사용자가 상단 프로필 옆 "회원 탈퇴"를 누른다.
2. 확인 창에 무엇이 지워지고 무엇이 남는지 보인다.
3. 입력 칸에 `탈퇴`를 쓰면 "탈퇴하기" 버튼이 눌린다.
4. 누르면 계정과 계정 기록이 지워지고 로그아웃되며 "탈퇴했어요" 안내가 보인다.

## 수용 기준

- [ ] AC-1: `docs/supabase/delete_account.sql`에 함수 `public.delete_my_account()`가 있다. 로그인한 사람 본인(`auth.uid()`)의 `auth.users` 줄만 지우고(→ `user_data`는 `on delete cascade`로 함께 지워짐), 로그인하지 않은 호출은 오류를 낸다. 실행 권한은 `authenticated`에게만 있다(`anon`, `public`은 회수). 여러 번 실행해도 괜찮다.
- [ ] AC-2: 로그인한 상태에서만 프로필 영역에 "회원 탈퇴" 버튼이 보인다. 로그아웃 상태에서는 보이지 않는다.
- [ ] AC-3: "회원 탈퇴"를 누르면 확인 창이 열린다. 창에는 (1) 계정과 계정에 저장된 기록이 지워져 되돌릴 수 없음, (2) 이 기기(브라우저)의 기록은 남음, (3) "백업 내보내기" 버튼, (4) 카카오·구글 쪽 연결은 각 서비스 설정에서 따로 끊을 수 있음이 적혀 있다.
- [ ] AC-4: 입력 칸에 정확히 `탈퇴`를 쓰기 전에는 "탈퇴하기" 버튼이 눌리지 않는다. "취소"나 Esc로 창을 닫으면 아무것도 바뀌지 않는다.
- [ ] AC-5: "탈퇴하기"를 누르면 `supabase.rpc("delete_my_account")`를 부르고, 성공하면 로그아웃하고 `muselog-sync-meta`를 지우고 창을 닫은 뒤 "탈퇴했어요. 이 기기의 기록은 그대로 있어요." 안내가 보인다. 다른 기록 키(`BACKUP_KEYS`)는 그대로다.
- [ ] AC-6: 실패하면(인터넷 끊김, SQL 미실행 등) 창 안에 "탈퇴하지 못했어요. 잠시 뒤 다시 시도해 주세요."가 보이고 로그인 상태와 기록은 그대로다. 누르는 동안 버튼은 "탈퇴하는 중…"으로 바뀌고 두 번 눌리지 않는다.
- [ ] AC-7: 탈퇴 뒤 같은 구글/카카오 계정으로 다시 로그인하면 새 계정으로 시작한다(서버 기록 없음 → 이 기기 기록을 올림, F-010 규칙대로).
- [ ] AC-8: 화면 폭 700px 이하에서도 확인 창이 화면 안에 들어온다.
- [ ] AC-9: `npm test`, `npm run build`, `npm run lint`가 오류 없이 끝난다.

## 비범위

- 카카오 "연결 끊기"(unlink) API·웹훅: 관리자 키가 필요해 서버 기능이 있어야 한다 (ROADMAP에 남김)
- 이 기기의 기록까지 지우기 (원하면 브라우저에서 사이트 데이터를 지우면 됨)
- 탈퇴 유예 기간, 탈퇴 사유 묻기

## 데이터 영향

| 항목 | 내용 |
|---|---|
| 사용하는 localStorage 키 | `muselog-sync-meta` (탈퇴 성공 시 지움). 다른 키는 읽기만(백업 내보내기) |
| 데이터 구조 변경 | 없음 |
| 마이그레이션 | 필요 없음 |
| 서버(Supabase) | 함수 `delete_my_account` 추가 (사용자가 SQL Editor에서 한 번 실행). 표 구조 변경 없음 |

## 확인 방법

- 자동: `npm test`, `npm run build`, `npm run lint`
- 사용자 준비: Supabase > SQL Editor에 `docs/supabase/delete_account.sql`을 붙여 넣고 Run
- 수동 (브라우저):
  1. 테스트용 계정(예: 카카오)으로 로그인 → "계정에 저장됨" 확인
  2. "회원 탈퇴" → 창 문구 확인 → `탈퇴` 입력 → "탈퇴하기"
  3. 로그아웃 상태와 안내 문구, 이 기기 기록이 그대로인지 본다
  4. Supabase Table Editor `user_data`와 Authentication > Users에서 그 계정 줄이 없어졌는지 본다
