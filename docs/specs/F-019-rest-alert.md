# F-019: 휴식 10분 알림

- 상태: 구현됨
- 작성일: 2026-11-03
- 관련 파일: `src/PracticeTimer.jsx`, `src/lib/timer.js`, `src/lib/timer.test.js`, `src/App.css`

## 목적

쉬다가 연습으로 돌아오는 것을 잊지 않게 한다. 연습 타이머(F-018)가 휴식 중이면 10분이 지날 때마다 화면 위쪽에 알림을 띄운다.

## 사용자 시나리오

1. 타이머에서 "휴식"을 누르고 앱을 보며 쉰다.
2. 10분이 지나면 화면 위쪽에 "휴식한 지 10분 지났어요" 알림이 뜬다.
3. 알림의 "다시 시작"을 눌러 연습으로 돌아가거나, "닫기"를 눌러 더 쉰다.
4. 계속 쉬면 20분, 30분에 다시 뜬다.

## 수용 기준

- [ ] AC-1: 이번 휴식을 시작한 지 10분이 되면 화면 위쪽에 "휴식한 지 10분 지났어요" 알림이 뜬다. 20분, 30분처럼 10분마다 숫자가 바뀌어 다시 뜬다. 10분 전에는 뜨지 않는다.
- [ ] AC-2: 시간은 이번 휴식 기준이다. "다시 시작"을 누르고 다음에 "휴식"을 누르면 0분부터 다시 센다. 앞선 휴식 시간은 더하지 않는다.
- [ ] AC-3: 알림은 어느 탭에서나 보이고, 페이지를 아래로 내려도 화면 위쪽에 남아 있다.
- [ ] AC-4: 알림에 "다시 시작"과 "닫기"가 있다. "다시 시작"은 타이머의 "다시 시작"과 같게 동작하고 알림이 사라진다. "닫기"는 알림만 닫고 휴식은 이어지며, 다음 10분이 되면 다시 뜬다.
- [ ] AC-5: 연습 중, 타이머를 시작하기 전, "연습 종료" 저장 칸을 연 동안에는 알림이 보이지 않는다. 저장 칸에서 "계속하기"로 휴식에 돌아오면, 이미 10분이 지났을 때 알림이 보인다. 단, 그 알림을 이미 닫았다면 다음 10분이 될 때까지 보이지 않는다.
- [ ] AC-6: 앱을 보지 않다가 돌아오거나 새로고침했을 때 10분이 지나 있으면, 지난 시간에 맞는 가장 가까운 숫자로 알림이 보인다(예: 25분이면 "20분"). 지나간 알림을 여러 개 쌓아 보여 주지 않는다. "닫기" 기록은 저장하지 않으므로 새로고침하면 다시 보일 수 있다.
- [ ] AC-7: 폭 700px 이하에서 알림이 화면 밖으로 넘치지 않고(페이지 가로 스크롤 없음), 버튼을 누를 수 있다.
- [ ] AC-8: 타이머의 다른 동작과 다른 탭의 기능이 이전과 똑같이 동작한다. 휴식 시간은 연습 기록에 더해지지 않는다.
- [ ] AC-9: `src/lib/timer.test.js`가 10분 전(9분 59초), 10분, 25분, 연습 중, 시계가 거꾸로 간 경우를 검사하고, `npm test`, `npm run build`, `npm run lint`가 오류 없이 끝난다.

## 비범위

- 앱 밖으로 보내는 알림(브라우저·휴대폰 알림, 권한 요청): 앱 화면을 보고 있을 때만 보인다. 휴대폰 화면이 꺼져 있거나 다른 앱을 쓰는 동안에는 알 수 없고, 돌아왔을 때 AC-6대로 보인다
- 알림 소리, 진동
- 10분 간격 바꾸기
- 연습 중 알림, 목표 시간 알림

## 확인 방법

- 자동: `npm test`, `npm run build`, `npm run lint`
- 수동 (브라우저):
  1. `npm run dev` 실행 후 http://localhost:5173/ 열기
  2. 타이머에서 "휴식"을 누른 뒤 10분을 기다린다 (개발자 도구로 `muselog-timer`의 `since`를 10분 앞으로 바꾸고 새로고침해도 된다)
  3. 알림의 "닫기"와 "다시 시작"을 각각 눌러 본다
  4. 다른 탭으로 옮기고 페이지를 내려 알림이 보이는지 본다
  5. 폭 700px, 375px, 320px에서 본다
