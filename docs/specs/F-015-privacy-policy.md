# F-015: 개인정보처리방침 페이지

- 상태: 구현됨
- 작성일: 2026-10-31
- 관련 파일: `public/privacy.html`(새로), `src/App.jsx`, `src/App.css`, `CLAUDE.md`, `docs/ROADMAP.md`

## 목적

구글 로그인을 "테스트" 상태에서 "게시"로 바꾸려면 Google Cloud 브랜딩에 개인정보처리방침 주소가 필요하다. MUSELOG가 어떤 정보를 왜 모으고, 어디에 얼마나 두고, 어떻게 지우는지 한국어로 알리는 페이지를 만든다.

## 사용자 시나리오

1. 사용자가 앱 맨 아래나 로그인 창의 "개인정보처리방침"을 누른다.
2. 새 탭에서 `https://muselog-swart.vercel.app/privacy.html`이 열리고, 방침 전문이 보인다.
3. 개발자는 이 주소를 Google Cloud 브랜딩의 "개인정보처리방침 링크"에 넣는다.

## 수용 기준

- [ ] AC-1: `public/privacy.html`이 혼자 열리는 페이지다(앱 코드 없이, `lang="ko"`, 파비콘 = 로고, 제목 `개인정보처리방침 · MUSELOG`). 개발 서버에서 http://localhost:5173/privacy.html, 배포 후 `/privacy.html`로 열린다.
- [ ] AC-2: 방침에 다음 항목이 모두 있다.
  1. 모으는 정보: 로그인 시 구글(이메일, 이름, 프로필 사진, 계정 고유번호)·카카오(닉네임, 프로필 사진·이메일은 동의한 경우만, 계정 고유번호)
  2. 로그인한 경우 계정에 저장하는 연습 기록(연습곡, 연습 기록, 일정, 루틴, 메트로놈 설정 등)
  3. 모으지 않는 것: 로그인하지 않으면 기록은 이 브라우저에만 저장되고 서버로 보내지 않음. 튜너 마이크 소리는 브라우저 안에서만 계산하고 저장·전송하지 않음. 광고·분석 추적 없음
  4. 이용 목적: 로그인, 기기 간 기록 저장·불러오기
  5. 보관 기간과 파기: 회원 탈퇴 즉시 계정과 계정 기록 삭제, 탈퇴 방법(로그인 → "회원 탈퇴")
  6. 처리 위탁: Supabase(로그인·기록 보관, 서울 ap-northeast-2), Vercel(사이트 전송, 미국), Google Fonts(글꼴, 미국). 제3자 제공 없음
  6-1. 국외 이전: 기록은 국외로 옮기지 않음. 접속 정보(IP·브라우저 정보)가 Vercel·Google로 가는 것을 표(받는 자·연락처·국가·항목·시기와 방법·목적·보유 기간)와 근거(제28조의8 제1항 제3호 가목), 거부 방법으로 적음
  6-2. 처리 근거(제15조 제1항 제4호), 파기 방법, 백업에 잠시 남을 수 있음, 브라우저 저장 공간(localStorage) 사용과 지우는 방법, 권리 요청 10일 안 처리, 14세 미만 계정 발견 시 삭제, 중요 변경 30일 전 고지와 변경 이력
  7. 이용자 권리: 열람·수정(앱에서 직접)·삭제(탈퇴)·백업 내보내기, 카카오·구글 연결 끊기 방법

## 비범위

- Google Cloud 브랜딩 입력과 "앱 게시" 누르기: 사용자가 Google Cloud에서 직접 한다 (구현 뒤 화면을 열고 넣을 값을 준비해 드림)
- 구글이 도메인 소유 확인(Search Console)을 요구하는 경우의 확인 파일 추가: 요구되면 다음 작업으로
- 이용약관 페이지
- 법률 검토 (개인 취미 프로젝트용 안내문이며 변호사 검토를 거친 문서가 아님)

## 확인 방법

- 자동: `npm test`, `npm run build`, `npm run lint`
- 수동 (브라우저):
  1. `npm run dev` 실행 후 http://localhost:5173/ 열기
  2. 맨 아래 "개인정보처리방침" → 새 탭에서 방침이 열리는지
  3. 로그아웃 상태에서 "로그인" → 창 안 링크
  4. 휴대폰 폭에서 방침 페이지 확인
