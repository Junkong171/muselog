# F-006: 고정 연습 루틴

- 상태: 구현됨 (수정 1차: 대시보드에 루틴 항목 표시, 배너는 대시보드에만, 날짜는 상단에 항상)
- 작성일: 2026-10-26
- 선행: F-005 (작업실 탭). PR #4가 아직 병합 전이라 `feature/workroom-metronome` 위에서 새 브랜치 `feature/daily-routine`으로 작업한다.
- 관련 파일: `src/App.jsx` (작업실 화면 분기 664줄 근처의 `<Metronome>` 위, 대시보드 D-DAY 카드 684줄 근처), 새 파일 `src/Routine.jsx`, `src/lib/routine.js`, `src/lib/routine.test.js`, `src/App.css`, `CLAUDE.md` (폴더 구조, localStorage 키 표)

## 목적

매일 하는 기본기 연습(워밍업, 스케일, 코드 체인지 등)을 매번 다시 적지 않도록, 루틴 목록을 한 번 만들어 두고 날마다 체크만 하게 한다. 루틴은 연습 도구가 모인 작업실 맨 위에 두고, 대시보드에서는 오늘 얼마나 했는지 한눈에 보이게 한다. 캘린더는 레슨·공연 같은 일정용으로 그대로 둔다.

## 사용자 시나리오

1. 사용자가 작업실을 열면 메트로놈 위에 "오늘의 루틴" 카드가 보인다. 처음엔 비어 있고 항목을 추가하라는 안내가 보인다.
2. "크로매틱 워밍업", "메이저 스케일", "코드 체인지"를 차례로 입력해 추가한다.
3. 워밍업을 마치고 "크로매틱 워밍업"을 눌러 체크한다. 카드 위쪽에 "1 / 3 완료"가 보인다.
4. 대시보드에 가면 "오늘의 루틴 1 / 3 완료" 카드가 보이고, "작업실 열기"를 누르면 작업실로 간다.
5. 다음 날 앱을 열면 루틴 목록 3개는 그대로이고 체크는 모두 비어 있다.

## 수용 기준

### 작업실의 루틴 카드

- [ ] AC-1: 작업실 화면에서 제목 영역 바로 아래, 메트로놈 카드 위에 "오늘의 루틴" 카드가 보인다.
- [ ] AC-2: 카드에 루틴 항목 이름 입력 칸과 "추가" 버튼이 있다. 이름을 쓰고 "추가"를 누르거나 Enter를 누르면 목록 맨 아래에 항목이 생기고 입력 칸이 비워진다. 앞뒤 공백만 있거나 빈 이름은 추가되지 않는다. 이름은 최대 40자까지 입력된다.
- [ ] AC-3: 항목이 하나도 없으면 "매일 하는 기본기 연습을 추가해 보세요. (예: 크로매틱 워밍업)" 같은 안내가 보인다.
- [ ] AC-4: 각 항목은 체크 표시와 이름으로 한 줄에 보인다. 항목(체크 표시나 이름)을 누르면 체크되고, 다시 누르면 체크가 풀린다. 체크된 항목은 체크 표시가 채워지고 이름이 흐려지거나 줄이 그어져 구분된다.
- [ ] AC-5: 각 항목 오른쪽에 삭제 버튼(×)이 있고, 누르면 그 항목이 목록에서 사라진다. (그 항목의 오늘 체크도 함께 사라진다)
- [ ] AC-6: 카드 위쪽에 "2 / 5 완료"처럼 오늘 체크한 수와 전체 항목 수가 보이고, 그 비율만큼 채워지는 진행 막대가 있다. 모두 체크하면 "오늘 루틴 완료!" 같은 문구가 함께 보인다.

### 날짜와 초기화

- [ ] AC-7: 루틴 목록(항목 이름과 순서)은 날짜와 상관없이 계속 남는다.
- [ ] AC-8: 체크는 그날에만 유효하다. 날짜가 바뀐 뒤(다음 날 앱을 열거나, 자정이 지난 뒤 화면을 다시 그릴 때) 모든 항목이 체크 안 된 상태로 보인다. 이전 날 체크 기록은 남기지 않는다.

### 대시보드 요약

- [ ] AC-9: 대시보드의 "다가오는 D-DAY" 카드 바로 위에 "오늘의 루틴" 요약 카드가 보인다. 카드에는 "2 / 5 완료" 문구, 진행 막대, "작업실 열기" 버튼이 있고, 버튼을 누르면 작업실 탭으로 바뀐다.
- [ ] AC-9a: 요약 카드에 루틴 항목 이름이 모두 체크 표시와 함께 보인다. (작업실 카드와 같은 순서, 같은 체크 상태) 대시보드에서도 항목을 눌러 체크하고 풀 수 있고, 그 결과는 작업실 카드와 숫자에 바로 반영된다. 항목 추가와 삭제는 작업실에서만 한다. (대시보드에는 입력 칸과 × 버튼이 없다)
- [ ] AC-10: 루틴 항목이 없으면 요약 카드에 "아직 루틴이 없어요." 안내와 "작업실 열기" 버튼이 보인다. 모두 체크했으면 "오늘 루틴 완료!"가 함께 보인다.
- [ ] AC-11: 요약 카드는 대시보드에만 보이고, 내 연습곡 탭(같은 화면 분기를 쓰는 탭)에는 보이지 않는다.

### 상단 날짜와 배너

- [ ] AC-11a: 화면 맨 위 줄(상단 바)의 경로 표시("Workspace / 작업실") 옆에 오늘 날짜가 "10월 26일 월요일" 형식으로 보이고, 모든 탭에서 계속 보인다.
- [ ] AC-11b: "음악이 쌓이는 시간, 나만의 기록을 만들어 봐." 배너는 대시보드에서만 보이고 다른 탭(내 연습곡, 연습 기록, 연습 통계, 캘린더, 작업실)에서는 보이지 않는다. 배너가 없는 탭에서도 아래 내용이 상단 바에 붙지 않고 적당히 띄워져 보인다.
- [ ] AC-11c: 날짜가 상단 바에 나오므로, 대시보드 배너의 작은 제목은 날짜를 빼고 "MY MUSIC SPACE"만 보인다.

### 저장

- [ ] AC-12: 루틴 목록은 새 localStorage 키 `muselog-routine`에, 오늘 체크 상태는 새 키 `muselog-routine-checks`에 저장되어 새로고침하거나 다른 탭에 갔다 와도 유지된다.
- [ ] AC-13: 두 키의 값이 없거나 깨져 있으면 앱이 멈추지 않는다. 목록은 이름이 없거나 문자열이 아닌 항목, id가 겹치는 항목을 버리고 읽는다. 체크 상태는 형식이 맞지 않거나 날짜가 오늘이 아니면 "체크 없음"으로 읽고, 목록에 없는 id는 무시한다. 이 처리는 `normalizeRoutine`, `todayChecks` 함수(`src/lib/routine.js`)로 한다.

### 공통

- [ ] AC-14: 순수 계산 함수 `normalizeRoutine`, `todayChecks`(저장값과 오늘 날짜 → 오늘 체크한 id 목록), `toggleCheck`, `routineProgress`(항목과 체크 → 완료 수·전체 수)를 `src/lib/routine.js`에 두고 `src/lib/routine.test.js`에 테스트를 추가한다. (날짜가 바뀌면 초기화, 깨진 값, 삭제된 항목의 체크 무시 포함)
- [ ] AC-15: 메트로놈, 내 연습곡, 연습 기록, 연습 통계, 캘린더가 이전과 똑같이 보이고 동작한다. 대시보드의 기존 카드(오늘의 연습 등, D-DAY, 연습곡 목록)도 그대로다.
- [ ] AC-16: `npm test`, `npm run build`, `npm run lint`가 오류 없이 끝난다. (lint 경고는 기존 개수보다 늘지 않는다)

## 비범위

- 항목별 목표 시간, 체크하면 연습 기록에 자동 저장
- 항목별 BPM 저장과 메트로놈 연결
- 연속 달성 일수, 날짜별 루틴 기록·통계
- 항목 이름 고치기, 순서 바꾸기(끌어서 옮기기) — 지우고 다시 추가하는 방식으로 대신
- 요일별로 다른 루틴, 루틴 여러 개 만들기
- 캘린더 변경 (일정용으로 그대로)

## 데이터 영향

| 항목 | 내용 |
|---|---|
| 사용하는 localStorage 키 | 새 키 `muselog-routine` (읽기 / 쓰기), 새 키 `muselog-routine-checks` (읽기 / 쓰기). 기존 키는 읽지도 쓰지도 않음 |
| 데이터 구조 변경 | 기존 키는 없음. `muselog-routine`: `[{ id: 숫자, title: 문자열(1~40자) }]` (보이는 순서 = 배열 순서). `muselog-routine-checks`: `{ date: "YYYY-MM-DD", done: [id, ...] }` (그날 체크한 항목 id) |
| 마이그레이션 | 필요 없음. 기존 사용자는 두 키가 없으므로 빈 루틴, 체크 없음으로 시작. 깨진 값은 AC-13대로 읽음 |

## 확인 방법

- 자동: `npm test`, `npm run build`, `npm run lint`
- 수동 (브라우저):
  1. `npm run dev` 실행 후 http://localhost:5173/ 열기
  2. 작업실에서 메트로놈 위에 "오늘의 루틴" 카드와 빈 안내가 보이는지 본다.
  3. 항목 3개를 추가하고(Enter와 "추가" 버튼 둘 다), 빈 이름은 추가되지 않는지 본다.
  4. 항목 하나를 눌러 체크하고 "1 / 3 완료"와 막대를 본다. 다시 눌러 체크가 풀리는지 본다. 모두 체크해서 "오늘 루틴 완료!"를 본다.
  5. 항목 하나를 ×로 지워 목록과 숫자가 바뀌는지 본다.
  6. 대시보드에서 요약 카드 숫자가 같고, "작업실 열기"로 이동하는지 본다. 내 연습곡 탭에는 요약 카드가 없는지 본다.
  6a. 대시보드 요약 카드에 항목 이름이 보이고, 눌러서 체크하면 작업실 카드에도 체크되어 있는지 본다.
  6b. 탭을 하나씩 옮기며 상단 바의 날짜가 계속 보이는지, 배너는 대시보드에서만 보이는지 본다.
  7. 새로고침해도 목록과 체크가 유지되는지 본다.
  8. 개발자 도구 콘솔에서 `muselog-routine-checks`의 date를 어제 날짜로 바꾸고 새로고침해 체크가 모두 비는지 본다.
  9. 메트로놈과 나머지 탭이 그대로인지 본다.
