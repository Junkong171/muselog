# F-036: 연습 종료하면 바로 저장 + 연습 기록 수정

- 상태: 구현됨
- 작성일: 2026-11-17
- 관련 파일: `src/PracticeTimer.jsx`, `src/App.jsx`, `src/App.css`, `src/lib/practiceLogs.js`(새 파일), `src/lib/practiceLogs.test.js`(새 파일)

## 목적

지금은 타이머의 "연습 종료"를 누르면 저장 칸이 뜨고, 곡·메모를 고른 뒤 "기록 저장"까지 눌러야 기록이 남는다(F-018). 저장을 귀찮아 하면 기록이 빠진다. 그래서 **"연습 종료"를 누르는 순간 바로 저장**하고, 곡·메모는 나중에 연습 기록 탭에서 고칠 수 있게 한다. 지금은 연습 기록을 고치는 기능이 없어서 함께 만든다.

## 사용자 시나리오

1. 어느 탭에서든 "지금 연습 시작" → 연습 → "연습 종료"를 누른다.
2. 바로 연습 기록이 저장되고(자유 연습, 쉰 시간을 뺀 분), 타이머 자리에 "연습 25분을 기록했어요"와 **"곡·메모 적기"**, **"닫기"** 버튼이 보인다.
3. "곡·메모 적기"를 누르면 연습 기록 탭으로 가서 방금 기록의 수정 칸이 열린다.
4. 곡을 고르고 메모를 적어 "수정 저장"을 누른다. (안 적어도 기록은 이미 남아 있다)
5. 예전 기록도 연습 기록 탭에서 "수정"을 눌러 곡·연습 시간·메모를 고칠 수 있다.

## 수용 기준

**연습 종료 = 바로 저장**
- [ ] AC-1: 타이머에서 "연습 종료"를 누르면 저장 칸 없이 곧바로 연습 기록이 하나 생긴다. 내용: 곡 없음(자유 연습), 연습 시간 = 쉰 시간을 뺀 분(지금 저장 칸에 채워지던 값과 같은 계산 `timerMinutes`, 최소 1분), 메모 "연습 내용 미입력", 날짜 = 누른 시각. 누적 연습 시간(`muselog-minutes`)도 그만큼 늘고, 재던 타이머(`muselog-timer`)는 지워진다.
- [ ] AC-2: 저장 뒤 타이머 자리에 "연습 N분을 기록했어요"(쉰 시간이 있으면 "· 휴식 m:ss 제외"도), "곡·메모 적기", "닫기" 버튼이 보인다. "닫기"를 누르면 원래의 "지금 연습 시작" 버튼으로 돌아간다. 이 안내가 보이는 동안에도 "지금 연습 시작"을 누를 수 있다.
- [ ] AC-3: "곡·메모 적기"를 누르면 연습 기록 탭으로 이동하고, 방금 저장한 기록의 수정 칸이 열려 있다. 안내는 사라진다.
- [ ] AC-4: 타이머를 켜 둔 채 잊어 연습 시간이 600분(`MAX_TIMER_MINUTES`)을 넘으면 바로 저장하지 않고, 지금처럼 저장 칸(곡·연습 시간·메모, 안내 문구, "기록 저장"/"계속하기"/"버리기")을 보여 시간을 고쳐 저장하게 한다.

**연습 기록 수정**
- [ ] AC-5: 연습 기록 탭의 각 기록에 "수정" 버튼이 "기록 삭제" 옆에 보인다.
- [ ] AC-6: "수정"을 누르면 그 기록 카드 안에 곡 선택(자유 연습 + 연습곡 목록), 연습 시간(분, 숫자), 메모 칸과 "수정 저장"/"취소" 버튼이 보이고, 지금 값이 채워져 있다. 메모가 "연습 내용 미입력"이면 메모 칸은 비어 있다. 한 번에 한 기록만 수정 칸이 열린다.
- [ ] AC-7: 기록의 곡이 연습곡 목록에서 지운 곡이면, 곡 선택에 그 곡 이름이 그대로 남아 있어 저장해도 곡 이름이 바뀌지 않는다.
- [ ] AC-8: "수정 저장"을 누르면 그 기록의 곡 이름·연습 시간·메모만 바뀌고 id와 날짜는 그대로다. 메모를 비우면 "연습 내용 미입력"으로 저장된다. 연습 시간을 바꾸면 누적 연습 시간도 차이만큼 바뀐다(예: 25분 → 40분이면 +15). 통계·대시보드가 바뀐 시간으로 보인다.
- [ ] AC-9: 연습 시간이 1~600 사이의 정수가 아니면 저장되지 않고 안내 문구가 보이며, 기록은 그대로다.
- [ ] AC-10: "취소"를 누르면 수정 칸이 닫히고 기록은 그대로다. 수정 중인 기록을 "기록 삭제"하면 지워지고 수정 칸도 닫힌다.
- [ ] AC-11: 기록 수정 계산(곡·시간·메모 정리, 잘못된 시간 거르기, 누적 시간 차이)은 순수 함수로 `src/lib/practiceLogs.js`에 있고 테스트가 있다.

**기존 동작**
- [ ] AC-12: 연습 기록 탭의 직접 기록 저장, 기록 삭제, 메트로놈 기록(타이머를 쓰지 않을 때), 휴식·다시 시작, 휴식 10분 알림, 다른 탭은 그대로다.
- [ ] AC-13: `npm test`, `npm run build`, `npm run lint`가 오류 없이 끝난다.

## 비범위

- 저장한 기록 되돌리기(실수로 종료했을 때 타이머 이어 가기). 대신 연습 기록 탭에서 지우거나 고칠 수 있다.
- 마지막에 연습한 곡 자동 선택
- 기록 날짜·시각 수정
- 대시보드 등 다른 곳에서 기록 수정

## 확인 방법

- 자동: `npm test`, `npm run build`, `npm run lint`
- 수동 (브라우저):
  1. `npm run dev` 실행 후 http://localhost:5173/ 열기
  2. "지금 연습 시작" → 잠시 뒤 "연습 종료" → 저장 칸 없이 "연습 1분을 기록했어요"가 보이는지
  3. 연습 기록 탭에 자유 연습 1분 기록이 생겼는지
  4. 다시 타이머 → 종료 → "곡·메모 적기" → 연습 기록 탭에서 수정 칸이 열렸는지, 곡·메모를 적어 저장
  5. 기록의 시간을 바꿔 저장하고 대시보드 누적 시간이 차이만큼 바뀌는지
