# F-030: 앱 첫 화면 빨리 열기 (코드 나눠 불러오기)

- 상태: 구현됨
- 작성일: 2026-11-07
- 관련 파일: `src/App.jsx`(탭 화면·로그인 연결을 필요할 때 불러오기, 자동 저장 조건), `src/lib/supabase.js`, `vite.config.js`(나눈 파일 목록을 첫 화면에 적기), `CLAUDE.md`

## 목적

지금은 앱을 열 때 모든 코드(약 542KB, 압축 156KB)를 한 번에 받는다. 이 중 로그인 연결(Supabase)이 거의 절반이고, 영감·수첩·작업실 도구는 그 탭을 열 때만 쓴다. 첫 화면에 꼭 필요한 코드만 먼저 받아 휴대폰에서 앱이 더 빨리 열리게 한다.

## 사용자 시나리오

1. 사용자가 앱을 연다. 대시보드가 전보다 빨리 보인다. 보이는 모습과 기능은 그대로다.
2. 영감·수첩·작업실 탭을 누르면 바로 열린다 (나머지 코드는 첫 화면이 뜬 뒤 미리 받아 둔다).
3. 인터넷이 끊겨도 (한 번 연 적이 있으면) 모든 탭이 전처럼 열린다.

## 수용 기준

- [ ] AC-1: `npm run build` 결과에서 첫 화면 JS 파일(index-*.js)이 압축 기준 100KB 이하이고, "500 kB보다 큰 파일" 경고가 나오지 않는다.
- [ ] AC-2: 로그인 연결 코드(Supabase)는 첫 화면 JS와 따로 나뉜 파일에 있고, 첫 화면이 뜬 뒤에 불러온다. 키가 있으면 로그인 버튼·로그인·로그아웃·자동 저장·불러오기·회원 탈퇴가 전처럼 동작한다. 키가 없으면 로그인 버튼 없이 전처럼 동작하고 Supabase 파일을 받지 않는다.
- [ ] AC-3: 영감·수첩 탭과 작업실 탭의 도구(루틴 제외: 메트로놈·기준음·튜너·연습 녹음·코드표)는 따로 나뉜 파일에 있다. 탭을 누르면 전과 같은 화면이 나온다. 받는 동안에는 "불러오는 중…"이 잠깐 보일 수 있다.
- [ ] AC-4: 배포본의 첫 화면(index.html)에 나뉜 파일 모두가 미리 받기(prefetch)로 적혀 있어, 오프라인 저장(sw.js)이 첫 방문 때 모든 파일을 저장한다. 한 번 연 뒤 인터넷을 끊고 다시 열어도 모든 탭이 열린다.
- [ ] AC-5: 나뉜 파일을 받지 못하면(예: 인터넷이 끊겼는데 저장된 파일도 없음) 화면이 하얗게 멈추지 않고 "화면을 불러오지 못했어요. 인터넷을 확인하고 다시 열어 주세요."가 보인다. 다른 탭은 계속 쓸 수 있다.
- [ ] AC-6 (버그 수정): 로그인한 상태에서 작업실의 기준음 설정만 바꿔도 2초 뒤 계정에 자동 저장된다. (지금은 기준음(`muselog-drone`)이 백업 키에는 있지만 자동 저장 조건에서 빠져 있어, 다른 기록이 바뀔 때까지 올라가지 않는다.)
- [ ] AC-7: 모든 탭(대시보드·내 연습곡·연습 기록·연습 통계·캘린더·작업실·영감·수첩)과 연습 타이머, 백업 내보내기·불러오기가 전처럼 동작한다.
- [ ] AC-8: `npm test`, `npm run build`, `npm run lint`가 오류 없이 끝난다.

## 비범위

- 화면 모양·기능 바꾸기
- App.jsx를 여러 파일로 나누는 정리 (구조만 바뀌고 속도 효과가 작음)
- 음원·아이콘 파일 줄이기, 다른 라이브러리로 바꾸기

## 확인 방법

- 자동: `npm test`, `npm run build`(파일 크기 확인), `npm run lint`
- 수동 (브라우저):
  1. `npm run dev` 실행 후 http://localhost:5173/ 열기, 모든 탭을 눌러 화면 확인
  2. `npm run build` 후 미리보기(`npx vite preview`)에서 index.html의 미리 받기 목록과 Supabase 파일이 따로 받아지는지 확인
  3. 미리보기에서 한 번 연 뒤 오프라인으로 바꾸고 새로고침해 모든 탭 확인
