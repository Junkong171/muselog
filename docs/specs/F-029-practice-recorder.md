# F-029: 작업실 연습 녹음

- 상태: 구현됨
- 작성일: 2026-11-07
- 관련 파일: 새 파일 `src/PracticeRecorder.jsx`, `src/voiceMemo.js`(녹음 길이·끝났을 때 저장 선택, 연습 녹음 저장소), `src/lib/inspiration.js` 또는 새 `src/lib/practiceRecordings.js`(+ 테스트), `src/App.jsx`(작업실에 카드 추가), `src/App.css`, `public/privacy.html`, `CLAUDE.md`

## 목적

노래나 연주를 녹음해서 바로 들어 보면 혼자서도 고칠 점을 찾을 수 있다. 다른 녹음 앱을 켜지 않고 메트로놈·기준음과 함께 작업실에서 녹음하고 다시 듣게 한다.

## 사용자 시나리오

1. 작업실 탭 튜너 아래 **"연습 녹음"** 카드에서 연습곡(선택, 기본 "자유 연습")을 고르고 **"녹음 시작"**을 누른다.
2. "● 녹음 중 1:23 / 10:00"이 보인다. 메트로놈·기준음을 켠 채로 녹음할 수 있다.
3. **"녹음 끝"**을 누르면 녹음이 목록 맨 위에 저장된다.
4. 목록의 녹음마다 날짜·시각, 곡 이름, 길이가 보이고 **듣기 / 파일로 저장 / 삭제**를 할 수 있다.

## 수용 기준

- [ ] AC-1: 작업실 탭의 튜너 카드와 코드표·스케일표 카드 사이에 제목 "연습 녹음" 카드가 있다. 카드에 "녹음은 이 기기에만 저장되고 백업·계정에는 들어가지 않아요."가 보인다.
- [ ] AC-2: 연습곡 선택 칸("자유 연습" + 내 연습곡)과 "녹음 시작" 버튼이 있다. 누르면 마이크를 켜고 "● 녹음 중 m:ss / 10:00"과 "녹음 끝" 버튼이 보인다. 녹음은 10분이 되면 저절로 끝난다.
- [ ] AC-3: "녹음 끝"을 누르거나 10분이 되면 녹음이 이 기기(IndexedDB `muselog-audio`의 새 저장소 `practice`)에 `{ id, createdAt(ISO), seconds, songTitle, blob }`으로 저장되고, 목록 맨 위에 나타난다.
- [ ] AC-4: 녹음 중에 다른 탭으로 옮기면 녹음이 멈추고, 그때까지 녹음한 것이 저장된다 (작업실로 돌아오면 목록에 있다). 마이크도 꺼진다.
- [ ] AC-5: 목록은 최근 녹음이 위에 오고, 각 줄에 날짜·시각(예: "11월 7일 오후 3:05"), 곡 이름(없으면 "자유 연습"), 길이(m:ss)가 보인다. 녹음이 없으면 "아직 녹음이 없어요."가 보인다.
- [ ] AC-6: "듣기"를 누르면 그 녹음이 재생되고 버튼이 "정지"로 바뀐다. 한 번에 하나만 재생된다. 재생이 끝나면 버튼이 "듣기"로 돌아온다.
- [ ] AC-7: "파일로 저장"을 누르면 녹음 파일이 기기에 내려받아진다. 파일 이름은 `muselog-녹음-YYYY-MM-DD-HHMM` + 녹음 형식에 맞는 확장자(.webm / .m4a / .ogg 등)다.
- [ ] AC-8: "삭제"를 누르면 "이 녹음을 삭제할까요?" 확인 뒤 기기에서 지워지고 목록에서 사라진다.
- [ ] AC-9: 녹음은 최대 20개까지 둔다. 20개가 차면 "녹음 시작"이 눌리지 않고 "녹음은 20개까지 둘 수 있어요. 안 쓰는 녹음을 지워 주세요."가 보인다.
- [ ] AC-10: 마이크가 막히면 튜너·음성 메모와 같은 안내 문구(`micErrorMessage`)가 보인다.
- [ ] AC-11: 기존 아이디어 음성 메모는 그대로다: 같은 IndexedDB의 `memos` 저장소 녹음이 지워지지 않고 수첩에서 계속 들린다. 영감 탭 음성 메모는 전처럼 2분까지이고, 녹음 중 탭을 옮기면 전처럼 버린다.
- [ ] AC-12: 개인정보처리방침에 연습 녹음이 추가된다: 마이크 사용(녹음 버튼을 누른 동안만), 기기 브라우저(IndexedDB)에만 저장·서버로 보내지 않음, 백업에 없어 사이트 데이터를 지우면 되살릴 수 없음, 작업실에서 듣고·저장하고·지울 수 있음. 시행일과 변경 이력(2026년 11월 7일)도 고친다.
- [ ] AC-13: 휴대폰 너비(360px)에서 카드와 목록이 가로로 넘치지 않는다.
- [ ] AC-14: `npm test`, `npm run build`, `npm run lint`가 오류 없이 끝난다.

## 비범위

- 녹음을 계정·백업에 넣기, 다른 기기에서 듣기
- 연습 시간을 연습 기록에 저장하기 (연습 타이머로)
- 녹음 자르기·편집, 녹음 이름·메모 쓰기, 곡별로 모아 보기
- 녹음하면서 반주 음원 틀기, 메트로놈 소리를 녹음에서 빼기
- 휴대폰 화면이 꺼진 동안 녹음 보장 (브라우저가 멈출 수 있음)

## 데이터 영향

| 항목 | 내용 |
|---|---|
| 사용하는 localStorage 키 | 없음 |
| 데이터 구조 변경 | IndexedDB `muselog-audio`의 버전을 1 → 2로 올리고 새 저장소 `practice`를 만든다 (열쇠 = 녹음 id, 값 = `{ id, createdAt, seconds, songTitle, blob }`) |
| 마이그레이션 | 버전을 올릴 때 이미 있는 `memos` 저장소와 그 안의 녹음은 그대로 두고, 없는 저장소만 만든다. 처음 쓰는 사용자는 두 저장소를 함께 만든다 |

## 확인 방법

- 자동: `npm test`, `npm run build`, `npm run lint`
- 수동 (브라우저):
  1. `npm run dev` 실행 후 http://localhost:5173/ 열기
  2. 수첩에 음성 메모가 있는 상태에서 작업실 → 연습 녹음 → 녹음 시작·끝 → 목록 확인
  3. 듣기·파일로 저장·삭제 확인, 녹음 중 다른 탭으로 갔다 와서 저장됐는지 확인
  4. 수첩의 기존 음성 메모가 계속 들리는지 확인
  5. 휴대폰 너비에서 카드 모양 확인
