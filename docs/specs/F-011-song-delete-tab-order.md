# F-011: 연습곡 삭제, 사이드바 탭 순서 바꾸기

- 상태: 구현됨
- 작성일: 2026-10-31
- 관련 파일: `src/App.jsx` (연습곡 카드의 "편집" 영역, 사이드바 `TABS.map` 565줄 근처, `TAB_ICONS`), `src/lib/songs.js`, 새 파일 `src/lib/tabs.js`, `src/lib/tabs.test.js`, `src/lib/backup.js` (`BACKUP_KEYS`), `src/lib/backup.test.js`, `src/App.css`, `CLAUDE.md` (localStorage 키 표)

## 목적

1. 더 이상 연습하지 않는 곡이나 잘못 추가한 곡을 지울 방법이 없다. 연습곡을 삭제할 수 있게 한다.
2. 사이드바 탭(대시보드 / 내 연습곡 / 연습 기록 / 연습 통계 / 캘린더 / 작업실)의 순서는 고정이다. 자주 쓰는 탭을 위로 올릴 수 있게, 끌어다 놓아(드래그) 순서를 바꾸고 그 순서를 기억한다.

## 사용자 시나리오

1. "내 연습곡"에서 "사랑은 늘 도망가" 카드의 "삭제"를 누르면 "'사랑은 늘 도망가' 곡을 삭제할까요? 이 곡으로 남긴 연습 기록은 그대로 남아요." 확인 창이 뜬다. 확인하면 카드가 사라진다.
2. 사이드바에서 "작업실" 탭을 잡고 "대시보드" 위로 끌어다 놓으면 작업실이 맨 위로 간다. 새로고침해도, 다른 기기에서 로그인해도 그 순서다.
3. 순서를 되돌리고 싶으면 WORKSPACE 옆 "기본 순서"를 누른다.

## 수용 기준

### 연습곡 삭제

- [ ] AC-1: 모든 연습곡 카드의 "편집" 옆에 "삭제" 글자 버튼이 있다(대시보드와 내 연습곡 모두).
- [ ] AC-2: "삭제"를 누르면 "'(곡 제목)' 곡을 삭제할까요? 이 곡으로 남긴 연습 기록은 그대로 남아요." 확인 창이 뜬다. 취소하면 아무것도 바뀌지 않는다.
- [ ] AC-3: 확인하면 그 곡만 목록과 `muselog-songs`에서 사라지고, 다른 곡의 순서·진행률·파트·목적과 표지 그림은 그대로다.
- [ ] AC-3a: 지금은 표지 그림(♫ ♪ ♬ ♩와 색)을 곡이 추가된 순서로 정해서, 앞의 곡을 지우면 뒤 곡들의 그림이 바뀐다. 표지 그림을 곡의 id로 정하도록 바꿔, 다른 곡을 지우거나 정렬을 바꿔도 각 곡의 그림이 그대로이게 한다. (예시 곡 3개는 지금과 같은 그림이 나온다)
- [ ] AC-4: 연습 기록·연습 통계의 곡별 시간·대시보드 오늘의 연습은 그대로다(기록에는 곡 제목이 글자로 저장되어 있음). 연습 기록 탭과 메트로놈의 곡 선택 목록에서는 지운 곡이 빠진다.
- [ ] AC-5: 편집 중인 곡을 지우면 편집 칸도 닫힌다. 마지막 곡까지 지우면 "첫 번째 연습곡을 추가해 보세요." 안내가 보인다.
- [ ] AC-6: 로그인한 상태라면 삭제도 다른 변경처럼 2초 뒤 계정에 저장된다.

### 사이드바 탭 순서

- [ ] AC-7: 사이드바의 탭 버튼을 마우스로 잡아 다른 탭 위·아래로 끌어다 놓으면 그 자리로 옮겨진다. 끄는 동안 놓일 자리가 선(또는 강조)으로 보인다. 각 탭의 아이콘은 탭을 따라간다.
- [ ] AC-8: 탭을 누르기만 하면(끌지 않으면) 지금처럼 그 탭으로 이동한다. 순서를 바꿔도 지금 보고 있는 탭은 그대로다.
- [ ] AC-9: 바꾼 순서는 새 localStorage 키 `muselog-tab-order`(탭 이름 배열)에 저장되어 새로고침해도 유지된다. 이 키는 백업(`BACKUP_KEYS`)에도 들어가서 백업 파일과 계정 동기화로 다른 기기에도 옮겨진다.
- [ ] AC-10: 순서가 기본과 다르면 사이드바 "WORKSPACE" 글자 옆에 "기본 순서" 버튼이 보이고, 누르면 기본 순서(대시보드, 내 연습곡, 연습 기록, 연습 통계, 캘린더, 작업실)로 돌아간다. 기본 순서일 때는 버튼이 보이지 않는다.
- [ ] AC-11 (마이그레이션): `muselog-tab-order`가 없거나 깨졌으면 기본 순서로 읽는다. 저장된 목록에 모르는 탭 이름이나 중복이 있으면 버리고, 빠진 탭(나중에 새로 생긴 탭 포함)은 기본 순서대로 뒤에 붙인다. 이 처리는 `normalizeTabOrder` 함수(`src/lib/tabs.js`)로 한다.
- [ ] AC-12: 예전 백업 파일(이 키가 없는 것)을 불러오면 탭 순서는 기본 순서가 된다. 백업 파일 형식 version은 1 그대로다(키가 하나 늘어도 예전 파일과 호환).

## 비범위

- 휴대폰(터치)에서 끌어서 순서 바꾸기 — 이번엔 마우스(컴퓨터)만. 휴대폰에서도 바꾼 순서는 그대로 보인다(동기화·백업)
- 탭 숨기기, 탭 이름 바꾸기
- 연습곡 순서 끌어서 바꾸기, 여러 곡 한꺼번에 삭제, 삭제 되돌리기
- 곡을 지울 때 그 곡의 연습 기록까지 지우기

## 확인 방법

- 자동: `npm test`, `npm run build`, `npm run lint`
- 수동 (브라우저):
  1. `npm run dev` 실행 후 http://localhost:5173/ 열기
  2. 곡 하나를 "삭제" → 취소하면 그대로, 확인하면 사라지는지. 다른 곡 표지 그림이 그대로인지. 연습 기록·통계가 그대로인지
  3. 사이드바에서 "작업실"을 "대시보드" 위로 끌어다 놓기 → 맨 위로 가는지, 새로고침해도 유지되는지, "기본 순서"로 돌아가는지
  4. 탭을 그냥 누르면 이동하는지
  5. 로그인한 상태에서 순서를 바꾸고 다른 창(InPrivate)에서 로그인해 같은 순서인지
