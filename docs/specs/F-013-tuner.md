# F-013: 작업실 튜너

- 상태: 구현됨
- 작성일: 2026-10-31
- 관련 파일: `src/lib/tuner.js`(새로), `src/lib/tuner.test.js`(새로), `src/Tuner.jsx`(새로), `src/App.jsx`, `src/App.css`, `CLAUDE.md`

## 목적

연습할 때 튜너 앱을 따로 켜지 않아도 되게, 작업실에서 마이크로 음 높이를 재어 가장 가까운 음과 얼마나 높은지·낮은지를 보여 준다. (연습 도구를 한곳에 모으기)

## 사용자 시나리오

1. 사용자가 작업실 탭에서 "튜너" 카드의 "튜너 켜기"를 누른다.
2. 브라우저가 마이크 사용 허락을 묻고, 사용자가 허용한다.
3. 기타 줄을 튕기거나 노래하면 카드에 음 이름(예: `A4 · 라`), 주파수(예: `440.0 Hz`), 바늘이 보인다.
4. 바늘이 가운데면 "맞음", 왼쪽이면 "낮음", 오른쪽이면 "높음"이라고 보인다.
5. "튜너 끄기"를 누르면 마이크가 꺼진다.

## 수용 기준

- [ ] AC-1: `src/lib/tuner.js`의 `frequencyToNote(freq)`가 기준음 A4 = 440Hz로 가장 가까운 음 이름·옥타브·센트(반음의 1/100, -50~+50)를 돌려준다. 예: 440 → A4 0센트, 261.63 → C4 약 0센트, 445 → A4 약 +20센트, 0·음수·숫자 아님 → `null`.
- [ ] AC-2: `detectPitch(samples, sampleRate)`가 사인파·여러 배음이 섞인 소리에서 주파수를 1% 안으로 찾는다 (41.2Hz 베이스 E1 ~ 1046.5Hz C6 테스트). 줄이 울리다 작아진 소리(최대 크기의 1/100, 진폭 0.005)도 찾는다. 거의 조용한 소리(진폭 0.001 잡음)와 음 높이 없는 잡음은 `null`.
- [ ] AC-3: 작업실 탭에 "튜너" 카드가 메트로놈 아래에 보이고, 처음에는 "튜너 켜기" 버튼과 안내 문구만 보인다. 이때 마이크를 쓰지 않는다.
- [ ] AC-4: 켠 상태에서 소리가 들리면 음 이름(영어 + 계이름, 예 `A4 · 라`), 주파수(소수 첫째 자리 Hz), 센트 바늘(-50~+50)이 보인다. |센트| ≤ 5면 "맞음"(초록), 그보다 낮으면 "낮음", 높으면 "높음"이 보인다.
- [ ] AC-5: 소리가 나는 동안에는 1초에 약 25번(40ms마다) 다시 재어 음 이름·주파수·바늘이 끊김 없이 따라 움직인다(한 번 잡고 멈추지 않음). 소리가 멈추면 마지막 음을 흐리게 1초쯤 보여 준 뒤 "소리를 내 보세요"로 바뀐다.
- [ ] AC-6: "튜너 끄기"를 누르거나 다른 탭으로 옮기면 마이크가 꺼진다(브라우저 주소창의 마이크 표시가 사라짐).
- [ ] AC-7: 마이크 허락을 거절하거나 마이크가 없거나 브라우저가 지원하지 않으면 카드에 한국어 안내(예: "마이크 사용이 허락되지 않았어요. 주소창 왼쪽 자물쇠에서 마이크를 허용해 주세요.")가 보이고 앱은 계속 동작한다.
- [ ] AC-8: 작업실 아래의 "튜너 등 다른 도구는 곧 추가될 예정이에요." 문구가 없다. 메트로놈·오늘의 루틴은 그대로 동작한다.
- [ ] AC-9: 화면 폭 700px 이하에서도 튜너 카드가 넘치지 않는다.
- [ ] AC-10: `npm test`, `npm run build`, `npm run lint`가 오류 없이 끝난다.
- [ ] AC-11: 작업실 탭에서는 위쪽 큰 카드 3개(오늘의 연습 / 이번 주 연습 / 하루 목표) 대신 얇은 한 줄 요약이 보인다: `오늘 N분 / 목표 M분 (P%)`, 얇은 진행 막대, `이번 주 W분`. 숫자는 큰 카드와 같은 값이다. 다른 탭에서는 큰 카드 3개가 그대로 보이고, 하루 목표 바꾸기도 그대로 된다.

## 비범위

- 기준음(A4) 바꾸기(예: 442Hz), 악기별 줄 목록(기타 EADGBE 표시), 기준음 소리 내기(드론)
- 튜너 결과를 연습 기록에 저장하기
- 새 localStorage 키 (설정을 저장하지 않는다)
- 작업실 한 줄 요약에서 하루 목표 바꾸기 (다른 탭의 "하루 목표" 카드에서 바꾼다)

## 확인 방법

- 자동: `npm test`, `npm run build`, `npm run lint`
- 수동 (브라우저):
  1. `npm run dev` 실행 후 http://localhost:5173/ 열기
  2. 작업실 탭 → "튜너 켜기" → 마이크 허용
  3. 휴대폰 튜너 앱이나 유튜브 "A 440Hz" 소리를 들려주고 `A4 · 라`, 약 440Hz, "맞음"이 보이는지 본다
  4. 기타·노래로 여러 음을 내 본다
  5. "튜너 끄기" 후 주소창 마이크 표시가 사라지는지 본다
