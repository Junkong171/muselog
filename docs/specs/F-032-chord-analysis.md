# F-032: 작업실 코드 분석 (다이아토닉·텐션·진행 분석)

- 상태: 구현됨
- 작성일: 2026-11-07
- 관련 파일: 새 파일 `src/ChordAnalysis.jsx`, 새 파일 `src/lib/chordAnalysis.js`(+ 테스트), `src/App.jsx`(작업실에 카드, 켜기·끄기 저장), `src/lib/backup.js`(+ 테스트), `src/App.css`, `public/privacy.html`, `public/licenses.html`, `CLAUDE.md`

## 목적

작곡하거나 곡을 카피할 때 "이 조에서 쓸 수 있는 코드가 뭐지?", "이 코드는 왜 조 밖인데 어울리지?"를 바로 알 수 있게 한다. 조의 다이아토닉 코드와 쓸 수 있는 텐션을 보여 주고, 직접 입력한 코드 진행을 분석한다.

## 사용자 시나리오

1. 작업실 탭 **"코드 분석"** 카드의 **"다이아토닉"** 보기에서 조(예: G 장조)를 고르면 그 조의 코드 7개가 도수·기능·텐션과 함께 보인다. 줄을 누르면 그 코드가 들린다.
2. **"진행 분석"** 보기에서 `C G/B Am7 D7 G7 C`처럼 코드를 띄어 써서 입력하면, 어울리는 조와 코드마다 도수·역할·구성음·텐션이 보이고, 투파이브 같은 흐름도 표시된다.
3. **"들어보기"**로 진행 전체를 피아노로 듣는다.

## 수용 기준

### 다이아토닉

- [ ] AC-1: 작업실 탭의 코드 전환 연습 카드 아래(F-031이 없으면 코드표·스케일표 아래)에 제목 "코드 분석" 카드가 있고, "다이아토닉" / "진행 분석" 보기 버튼이 있다 (기본 다이아토닉).
- [ ] AC-2: 조(근음 12개)와 "장조" / "단조(내추럴 마이너)"를 고르면 7줄이 보인다. 줄마다 도수(로마 숫자), 3화음, 7화음, 기능, 쓸 수 있는 텐션이 있다. 예: C 장조 →
  - I · C · Cmaj7 · 토닉 · 9, 13
  - ii · Dm · Dm7 · 서브도미넌트 · 9, 11
  - iii · Em · Em7 · 토닉 · 11
  - IV · F · Fmaj7 · 서브도미넌트 · 9, #11, 13
  - V · G · G7 · 도미넌트 · 9, 13
  - vi · Am · Am7 · 토닉 · 9, 11
  - vii° · Bdim · Bm7b5 · 도미넌트 · 11, b13
  - A 단조 → i Am Am7 토닉 9, 11 / ii° Bdim Bm7b5 서브도미넌트 11, b13 / bIII C Cmaj7 토닉 9, 13 / iv Dm Dm7 서브도미넌트 9, 11 / v Em Em7 도미넌트 11 / bVI F Fmaj7 서브도미넌트 9, #11 / bVII G G7 서브도미넌트 9, 13
- [ ] AC-3: 텐션은 실제 음 이름도 함께 보인다 (예: C 장조 I → "9(D), 13(A)"). 줄을 누르면 그 7화음이 피아노로 2초 들린다.

### 진행 분석

- [ ] AC-4: 입력 칸에 코드를 띄어쓰기(또는 `|`, `-`, `,`)로 구분해 입력하고 "분석"을 누르면 결과가 보인다. 코드는 32개까지.
- [ ] AC-5: 읽을 수 있는 코드: 근음(C~B, #/b) + 종류(없음=메이저, m, 7, maj7(M7, Δ), m7, 6, m6, 9, maj9, m9, 11, m11, 13, add9, sus2, sus4, 7sus4, dim, dim7, aug(+), m7b5(ø), mmaj7, 7b9, 7#9, 7#11, 7b13) + 선택적 `/베이스`. 읽을 수 없는 코드가 있으면 결과 대신 "읽을 수 없는 코드: X" 안내가 보인다.
- [ ] AC-6: 어울리는 조를 자동으로 찾아 "어울리는 조: C 장조 (6개 중 5개가 조 안의 코드)"처럼 보인다. 조 선택 칸("자동" + 24개 조)으로 바꿀 수 있고, 바꾸면 그 조로 다시 분석한다.
- [ ] AC-7: 코드마다 이름, 도수(예: V7, ii7, IVmaj7), 구성음, 텐션(코드에 들어 있는 9·11·13 음, 예: G7(b9) → "텐션 b9(Ab)"), 역할이 보인다. 역할은 다음 중 하나다.
  - 다이아토닉 (토닉 / 서브도미넌트 / 도미넌트)
  - 세컨더리 도미넌트 (예: C 장조의 D7 → "V7/V", 설명 "G 쪽으로 가는 도미넌트")
  - 트라이톤 대리 (예: C 장조의 Db7 → "subV7", 설명 "C 쪽으로 가는 대리 도미넌트")
  - 차용화음 (예: C 장조의 Fm, Bb, Ab → "같은 으뜸음 C 단조에서 빌려 온 코드")
  - 조 밖의 코드 (위에 해당하지 않음)
- [ ] AC-8: 흐름 표시: ii–V(투파이브), ii–V–I(투파이브원), V–I(도미넌트 해결)가 이어진 코드 위에 표시된다. 다른 조로 가는 ii–V도 표시된다 (예: C 장조의 Em7 A7 Dm7 → 도착 코드의 3화음 이름으로 "Dm 쪽으로 가는 투파이브"). 코드 이름 뒤 조사(로/으로)가 틀리지 않게 "쪽으로"를 쓴다.
- [ ] AC-9: "들어보기"를 누르면 진행이 피아노로 한 코드에 2초씩 들리고 지금 코드가 강조된다. 입력·조를 바꾸거나 다른 탭으로 가면 멈춘다. 음원 출처(FluidR3 GM, CC BY 3.0)가 카드에 보인다.

### 공통

- [ ] AC-10: 분석 내용(입력한 진행, 고른 조)은 저장하지 않는다. 입력한 진행은 탭을 옮기면 지워진다.
- [ ] AC-13: 카드 제목 옆에 켜기·끄기 버튼("켜짐" / "꺼짐", 기본 켜짐)이 있다. 끄면 카드가 제목 줄과 "코드 분석이 꺼져 있어요." 한 줄로 줄어들고, 나던 소리도 멈춘다. 다시 켜면 처음(다이아토닉 보기)부터 보인다. 켜기·끄기는 localStorage 키 `muselog-chord-analysis`에 `{ on: true/false }`로 저장되어 다시 열어도 그대로이고(없거나 깨지면 켜짐), `BACKUP_KEYS`에 들어가 백업·계정 동기화에 함께 담긴다. 개인정보처리방침의 화면 설정 항목에 추가된다.
- [ ] AC-11: 휴대폰 너비(360px)에서 표와 결과가 가로로 넘치지 않는다 (줄바꿈 또는 카드 안 스크롤).
- [ ] AC-12: 분석 계산은 `src/lib/chordAnalysis.js`의 순수 함수이고, 위 예시(AC-2, AC-6~8)를 자동 테스트로 확인한다. `npm test`, `npm run build`, `npm run lint`가 오류 없이 끝난다.

## 비범위

- 하모닉·멜로딕 마이너 다이아토닉, 모드(도리안 등) 분석
- 전조(곡 중간에 조가 바뀜)를 찾아 구간별로 나누기
- 분석 결과를 아이디어·수첩에 저장하기
- 곡 제목으로 코드 찾아 주기, 오디오에서 코드 알아내기
- 코드를 몇 박씩 치는지(리듬) 입력하기

## 확인 방법

- 자동: `npm test`(분석 예시), `npm run build`, `npm run lint`
- 수동 (브라우저):
  1. `npm run dev` 실행 후 http://localhost:5173/ → 작업실 → 코드 분석
  2. C 장조·A 단조 다이아토닉 표 확인, 줄 눌러 듣기
  3. `C G/B Am7 D7 G7 C`, `Cmaj7 Em7 A7 Dm7 G7 Cmaj7`, `C Fm C Db7 C` 입력해 조·도수·역할·흐름 확인, 들어보기
  4. `Cx7`처럼 틀린 코드 입력 시 안내 확인, 휴대폰 너비에서 모양 확인
