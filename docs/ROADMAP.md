## 로그인·계정

- **개인정보처리방침 페이지(F-015에서 완료) + 구글 앱 게시**: 지금 구글 로그인은 "테스트" 상태라 등록한 테스트 사용자만 로그인할 수 있다. MUSELOG에 개인정보처리방침 페이지(`/privacy.html`)를 만들고, Google Cloud 브랜딩에 홈페이지·개인정보처리방침 링크를 넣은 뒤 "앱 게시"를 누르면 누구나 구글로 로그인할 수 있다.
  - 게시 직전 할 일: 방침 전체를 앱과 대조해 점검하고, 시행일을 게시일로 바꾸고, 변경 이력을 "처음 만듦" 한 줄로 정리한다. 그전까지는 새 저장 항목만 목록에 추가하고, 기록을 새로운 곳으로 보내게 되면 바로 고친다.
- **카카오 회원 탈퇴 웹훅**: 카카오 디벨로퍼스가 권장하는 "연결 해제 웹훅"을 설정해, 카카오에서 연결을 끊은 사용자의 정보를 정리한다.
- **회원 탈퇴 / 계정 기록 삭제 화면(F-014에서 완료)**: 사용자가 직접 계정과 서버 기록(`user_data`)을 지울 수 있게 한다.
- **네이버 로그인**: Supabase 기본 지원이 없어 별도 작업이 필요하다.
- **동기화 실제 화면 확인**: 선택 창(두 기기 기록이 다를 때)과 오프라인 "저장 실패 · 다시 시도"는 판단 로직 테스트만 있고 실제 화면으로는 아직 확인하지 않았다.
- **다른 기기 변경 실시간 반영**: 지금은 앱을 다시 열거나 새로고침해야 반영된다.
- **두 기기 기록 항목별 합치기**: 지금은 둘 중 하나를 고르기만 한다.

## 화면·브랜드

- **로고 교체(F-012에서 완료)**: 카카오 앱 아이콘으로 쓴 시안 8번 "연습 노트"를 사이트 탭 아이콘(파비콘)과 사이드바 로고에도 쓴다.

## 곡 쓰기

- **영감·수첩 탭(F-017에서 완료)**: 키워드 뽑기, 장르·분위기·조별 코드 진행과 들어보기, 아이디어 쓰기(영감)와 다시 보기(수첩).
- **수첩에서 저장한 코드 다시 듣기, 아이디어 검색**: F-017에서 뺀 것.
- **레퍼런스 곡 분석**: 레퍼런스 곡을 넣으면 비슷한 곡을 찾거나 분석해 주는 기능. 어떤 입력(곡 이름, 음원 파일)으로 할지, 외부 서비스와 서버가 필요한지, 음원 저작권을 어떻게 다룰지 먼저 정한다.
- **AI 추천**: 주제에 맞춘 키워드·코드 추천. AI 키를 숨길 서버와 사용 요금이 필요하다.

## 작업실 도구

- **튜너(F-013에서 완료)**: 마이크로 음 높이를 재는 도구.
- **기준음(드론)**, **연습 타이머**, **녹음해서 다시 듣기**, **코드표·스케일표**.
- **루틴 항목별 목표 시간·BPM 연결, 연속 달성 일수** (F-006에서 뺀 것).
